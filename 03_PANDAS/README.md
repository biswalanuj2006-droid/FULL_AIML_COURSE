# Module 03: Pandas

## What You Will Learn

- Series and DataFrame fundamentals
- Reading and writing data (CSV, Excel, JSON)
- Data selection and filtering
- Data cleaning and missing values
- GroupBy and aggregation
- Merge, join, and concatenation
- String and datetime operations
- Practical data manipulation patterns

## Why You Need It

Pandas is the primary tool for data manipulation in Python. Every ML project starts with loading, cleaning, and exploring data — Pandas is the tool that does all of that. You will use Pandas in nearly every single module from here on.

## Prerequisites

- Module 01: Python for AI/ML
- Module 02: NumPy (arrays, indexing, operations)

## What You Will Be Able to Do After This Module

1. Load datasets from CSV, Excel, JSON
2. Explore data shape, types, and statistics
3. Handle missing values, duplicates, and outliers
4. Filter, sort, and transform data
5. Group data and compute aggregations
6. Merge multiple datasets
7. Create features from raw data
