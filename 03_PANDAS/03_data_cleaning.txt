1. MISSING VALUES
================================================================================

DETECTING:
    df.isnull()              # Boolean DataFrame (True = null)
    df.isnull().sum()        # Count nulls per column
    df.isnull().sum().sum()  # Total nulls
    df.isnull().mean() * 100 # Percentage nulls per column

    # Columns with missing values
    missing_cols = df.columns[df.isnull().any()].tolist()

HANDLING — REMOVAL:
    df.dropna()                      # Drop rows with ANY null
    df.dropna(subset=["age"])        # Drop rows where 'age' is null
    df.dropna(thresh=3)              # Keep rows with at least 3 non-null values
    df.dropna(axis=1)                # Drop columns with any null

HANDLING — IMPUTATION:
    df["age"].fillna(0)                          # Fill with constant
    df["age"].fillna(df["age"].mean())           # Fill with mean
    df["age"].fillna(df["age"].median())         # Fill with median
    df["age"].fillna(df["age"].mode()[0])        # Fill with mode
    df["age"].fillna(method="ffill")             # Forward fill
    df["age"].fillna(method="bfill")             # Backward fill

    # For entire DataFrame
    df.fillna(df.mean(numeric_only=True))        # Fill all numeric with mean

ML USE:
    # Strategy depends on the ML algorithm
    # Tree-based models (RF, XGBoost) can handle NaN natively
    # Linear models, neural networks require imputation

================================================================================
