# Module 10: Regression

Predicting continuous values — house prices, demand, temperature, sales.

## What You Will Learn

- Linear regression: model, least squares, closed form, assumptions
- Multiple and polynomial regression
- Regularization: Ridge (L2), Lasso (L1), Elastic Net — and what each does
- Tree-based regression: Decision Tree, Random Forest, Gradient Boosting
- SVR and KNN regression overview
- Regression diagnostics: residuals, outliers, multicollinearity
- Evaluation: MAE, MSE, RMSE, R², adjusted R² — when each is right
- Feature scaling's role in penalized linear models
