# TRANSFORMERS — PROJECTS

## PROJECT 1 — TEXT CLASSIFICATION WITH BERT (Level 2)

### Problem Statement
Fine-tune BERT for sentiment classification.

### Requirements
- Load pre-trained BERT model
- Tokenize text data
- Fine-tune for classification
- Evaluate on test set
- Compare with baseline (TF-IDF + Logistic Regression)
- Export model for inference

### Dataset
- IMDB Reviews or SST-2

### Expected Output
- Fine-tuned BERT model
- Accuracy > 90%
- Comparison with baseline
- Inference script

## PROJECT 2 — NAMED ENTITY RECOGNITION (Level 2)

### Problem Statement
Build an NER system using transformers.

### Requirements
- Load NER dataset (CoNLL-2003 or WNUT)
- Fine-tune BERT for token classification
- Evaluate with entity-level F1
- Build prediction function
- Visualize entities

### Expected Output
- Fine-tuned NER model
- Entity-level metrics
- Prediction visualization
- Inference script
