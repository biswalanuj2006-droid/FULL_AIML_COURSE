================================================================================
1. WHAT IS A TRANSFORMER?
================================================================================

INTUITION
---------
The Transformer is an architecture that uses SELF-ATTENTION to process
all positions in a sequence simultaneously (parallel), replacing the
sequential processing of RNNs.

Published in 2017: "Attention Is All You Need" (Vaswani et al.)

KEY INNOVATION: Self-attention + positional encoding replaces recurrence.

WHY IT WON
----------
1. Parallel processing (faster training than RNNs)
2. Captures long-range dependencies directly
3. Scales well to very large datasets and models
4. Foundation for BERT, GPT, and virtually all modern NLP

================================================================================
2. TRANSFORMER ARCHITECTURE
================================================================================

ORIGINAL TRANSFORMER
--------------------
ENCODER: processes input sequence
DECODER: generates output sequence

ENCODER STACK (N layers):
  Input Embedding → Positional Encoding →
  [Multi-Head Self-Attention → Add & Layer Norm →
   Feed-Forward Network → Add & Layer Norm] × N

DECODER STACK (N layers):
  Output Embedding → Positional Encoding →
  [Masked Multi-Head Self-Attention → Add & Layer Norm →
   Multi-Head Cross-Attention → Add & Layer Norm →
   Feed-Forward Network → Add & Layer Norm] × N

================================================================================
3. KEY COMPONENTS
================================================================================

3.1 POSITIONAL ENCODING
------------------------
Since transformers process all positions simultaneously,
they don't inherently know word ORDER.

Positional encoding adds position information to embeddings.

Sinusoidal encoding:
  PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
  PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

IMPLEMENTATION
--------------
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        div_term = torch.exp(torch.arange(0, d_model, 2).float() *
                            -(np.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        pe = pe.unsqueeze(0)
        self.register_buffer('pe', pe)

    def forward(self, x):
        return x + self.pe[:, :x.size(1)]

3.2 MULTI-HEAD SELF-ATTENTION
-------------------------------
(See Module 25 for detailed explanation)

Each position attends to all positions in the sequence.

3.3 FEED-FORWARD NETWORK
-------------------------
Two linear transformations with ReLU in between:
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

Typically: d_model → 4×d_model → d_model

3.4 ADD & LAYER NORMALIZATION
------------------------------
Residual connection + layer normalization
LayerNorm(x + Sublayer(x))

Why residual connections:
- Help gradients flow during training
- Allow stacking many layers

4. ENCODER-ONLY: BERT
================================================================================

BIDIRECTIONAL — sees entire input at once.

BERT = Bidirectional Encoder Representations from Transformers

BERT BASE: 12 layers, 768 hidden, 12 heads, 110M parameters
BERT LARGE: 24 layers, 1024 hidden, 16 heads, 340M parameters

PRETRAINING TASKS:
1. Masked Language Model (MLM): predict masked words
   "The cat [MASK] on the mat" → "sat"
2. Next Sentence Prediction (NSP): predict if B follows A

USING BERT
-----------
from transformers import BertTokenizer, BertForSequenceClassification
import torch

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForSequenceClassification.from_pretrained(
    'bert-base-uncased', num_labels=2
)

# Tokenize
inputs = tokenizer("I love this movie!", return_tensors='pt',
                   padding=True, truncation=True)

# Predict
with torch.no_grad():
    outputs = model(**inputs)
    prediction = torch.argmax(outputs.logits, dim=1)
    print(f"Prediction: {prediction.item()}")

5. DECODER-ONLY: GPT
================================================================================

AUTOREGRESSIVE — generates text one token at a time, left to right.

GPT = Generative Pre-trained Transformer

GPT-2: 1.5B parameters
GPT-3: 175B parameters

PRETRAINING: Next token prediction
"The cat sat on the" → predict "mat"

USING GPT FOR TEXT GENERATION
------------------------------
from transformers import pipeline

generator = pipeline('text-generation', model='gpt2')

output = generator("The future of AI is", max_length=50, num_return_sequences=1)
print(output[0]['generated_text'])

USING GPT FOR CLASSIFICATION
-----------------------------
# Use the last token's hidden state for classification
from transformers import GPT2Tokenizer, GPT2Model

tokenizer = GPT2Tokenizer.from_pretrained('gpt2')
model = GPT2Model.from_pretrained('gpt2')

inputs = tokenizer("Hello world", return_tensors='pt')

# Use last hidden state of last token
last_hidden = outputs.last_hidden_state[:, -1, :]

7. COMPLETE TRANSFORMER FROM SCRATCH
================================================================================

import torch
import torch.nn as nn
import numpy as np

class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model)
        )
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # Self-attention with residual
        attn_out, _ = self.attention(x, x, x, mask)
        x = self.norm1(x + self.dropout(attn_out))

        # Feed-forward with residual
        ff_out = self.ff(x)
        x = self.norm2(x + self.dropout(ff_out))

        return x

class TransformerEncoder(nn.Module):
    def __init__(self, vocab_size, d_model, num_heads, d_ff,
                 num_layers, max_len=512):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, max_len)
        self.layers = nn.ModuleList([
            TransformerBlock(d_model, num_heads, d_ff)
            for _ in range(num_layers)
        ])
        self.norm = nn.LayerNorm(d_model)

    def forward(self, x, mask=None):
        x = self.embedding(x)
        x = self.pos_encoding(x)

        for layer in self.layers:
            x = layer(x, mask)

        return self.norm(x)

# Usage
model = TransformerEncoder(
    vocab_size=30000, d_model=512, num_heads=8,
    d_ff=2048, num_layers=6
)

x = torch.randint(0, 30000, (2, 128))  # batch=2, seq_len=128
output = model(x)
print(output.shape)  # (2, 128, 512)

9. FINE-TUNING TRANSFORMERS
================================================================================

from transformers import (BertForSequenceClassification, BertTokenizer,
                          Trainer, TrainingArguments)
from datasets import load_dataset

# Load data
dataset = load_dataset('imdb')

# Load model
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForSequenceClassification.from_pretrained(
    'bert-base-uncased', num_labels=2
)

# Tokenize
def tokenize(batch):
    return tokenizer(batch['text'], padding=True, truncation=True,
                     max_length=512)

dataset = dataset.map(tokenize, batched=True)

# Training arguments
training_args = TrainingArguments(
    output_dir='./results',
    num_train_epochs=3,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=64,
    warmup_steps=500,
    weight_decay=0.01,
    logging_dir='./logs',
    evaluation_strategy='epoch'
)

# Trainer
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=dataset['train'],
    eval_dataset=dataset['test']
)

trainer.train()

10. COMMON MISTAKES
================================================================================

MISTAKE 1: Not using attention masks
  RIGHT: Always pass attention_mask for variable-length sequences

MISTAKE 2: Training transformers from scratch on small data
  RIGHT: Use pretrained models, fine-tune on your data

MISTAKE 3: Using too high learning rate
  RIGHT: Use 2e-5 to 5e-5 for fine-tuning BERT/GPT

MISTAKE 4: Not freezing early layers
  RIGHT: Freeze base model, fine-tune only classification head for small data

MISTAKE 5: Ignoring max sequence length
  RIGHT: Truncate or chunk long documents
