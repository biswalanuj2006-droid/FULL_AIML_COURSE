  4. Structural checks: module-prefix uniqueness, empty dirs.

Issues found and fixed during this pass:
  - Windows cp1252 crash: examples printing emoji (unicode) raised
    UnicodeEncodeError whenever stdout was a pipe. verify_course.py now
    runs subprocesses with -X utf8 / PYTHONUTF8=1 / PYTHONIOENCODING.

    inside a captured subprocess on a GUI backend. Runner now forces
    MPLBACKEND=Agg (headless), so show() is a no-op for CI runs while
    interactive use is unchanged.

    classified a 200x200 = 40,000-point boundary grid with a pure-Python
    per-point distance loop (>120 s). predict() is now vectorized (same
    math, numpy broadcast distance matrix; _predict_single kept as the
    step-by-step reference) and the grid is 120x120. Demo: ~8 s, PASS.
