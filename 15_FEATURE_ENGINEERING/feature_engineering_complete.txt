1. WHAT IS FEATURE ENGINEERING?
================================================================================

INTUITION
---------
Feature engineering = creating new input variables from raw data
to help models learn better.

Think of it as translating raw data into a language the model
can understand more easily.

"Garbage in, garbage out" — good features make simple models shine.
"A problem well-stated is half-solved" — good features make the problem easier.

2. NUMERICAL TRANSFORMATIONS
================================================================================

2.1 LOG TRANSFORMATION
----------------------
Use when: data is right-skewed (income, prices, population)

import numpy as np

df['log_income'] = np.log1p(df['income'])  # log(1+x) handles zeros

# Inverse: np.expm1(df['log_income'])

2.2 SQUARE ROOT
---------------
Use when: moderate skew, count data

df['sqrt_count'] = np.sqrt(df['count'])

2.3 POWER TRANSFORMATIONS
-------------------------
Makes data more Gaussian-like.

from sklearn.preprocessing import PowerTransformer

pt = PowerTransformer(method='yeo-johnson')  # handles zeros/negatives
df['power_income'] = pt.fit_transform(df[['income']])

2.4 BINNING / DISCRETIZATION
-----------------------------
Convert continuous to categorical.

df['age_group'] = pd.cut(df['age'],
    bins=[0, 18, 35, 55, 100],
    labels=['young', 'adult', 'middle', 'senior'])

# Equal-width bins
df['income_bin'] = pd.cut(df['income'], bins=10)

# Equal-frequency bins (quantiles)
df['income_quartile'] = pd.qcut(df['income'], q=4)

2.5 POLYNOMIAL FEATURES
------------------------
Create interaction and higher-order terms.

from sklearn.preprocessing import PolynomialFeatures

poly = PolynomialFeatures(degree=2, interaction_only=False)
X_poly = poly.fit_transform(X)

# This creates: x1, x2, x1², x1*x2, x2²

2.6 RATIO FEATURES
-------------------
df['debt_to_income'] = df['debt'] / (df['income'] + 1)
df['bath_to_bed'] = df['bathrooms'] / (df['bedrooms'] + 1)

2.7 DIFFERENCE FEATURES
------------------------
df['price_change'] = df['current_price'] - df['previous_price']
df['price_pct_change'] = (df['current_price'] - df['previous_price']) / (df['previous_price'] + 1)

3. DATE/TIME FEATURES
================================================================================

df['date'] = pd.to_datetime(df['date'])

df['year'] = df['date'].dt.year
df['month'] = df['date'].dt.month
df['day'] = df['date'].dt.day
df['day_of_week'] = df['date'].dt.dayofweek  # 0=Monday
df['is_weekend'] = df['date'].dt.dayofweek >= 5
df['hour'] = df['date'].dt.hour
df['quarter'] = df['date'].dt.quarter
df['day_of_year'] = df['date'].dt.dayofyear

# Cyclical encoding (for periodic features)
df['month_sin'] = np.sin(2 * np.pi * df['month'] / 12)
df['month_cos'] = np.cos(2 * np.pi * df['month'] / 12)
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)

WHY CYCLICAL?
-------------
Month 12 and Month 1 are close (December → January)
But numerically 12 and 1 are far apart!
Sin/cos encoding makes them close.

4. TEXT FEATURES
================================================================================

4.1 BASIC TEXT FEATURES
------------------------
df['text_length'] = df['text'].str.len()
df['word_count'] = df['text'].str.split().str.len()
df['avg_word_length'] = df['text'].apply(
    lambda x: np.mean([len(w) for w in x.split()]) if isinstance(x, str) else 0
)
df['uppercase_ratio'] = df['text'].apply(
    lambda x: sum(1 for c in str(x) if c.isupper()) / (len(str(x)) + 1)
)
df['exclamation_count'] = df['text'].str.count('!')
df['question_count'] = df['text'].str.count(r'\?')

4.2 TF-IDF FEATURES
--------------------
from sklearn.feature_extraction.text import TfidfVectorizer

tfidf = TfidfVectorizer(max_features=100, stop_words='english')

4.3 COUNT VECTORIZER
--------------------

================================================================================
5. CATEGORICAL FEATURES
================================================================================

5.1 ONE-HOT ENCODING
---------------------
Creates binary column for each category.

df_encoded = pd.get_dummies(df, columns=['color'], drop_first=True)

from sklearn.preprocessing import OneHotEncoder

ohe = OneHotEncoder(sparse_output=False, drop='first')
encoded = ohe.fit_transform(df[['color']])

USE WHEN: nominal categories (< 10 categories)
AVOID WHEN: high cardinality (> 20 categories)

5.2 ORDINAL ENCODING
---------------------
Maps categories to ordered integers.

order = {'low': 0, 'medium': 1, 'high': 2}
df['priority_encoded'] = df['priority'].map(order)

USE WHEN: categories have natural order

5.3 FREQUENCY ENCODING
-----------------------
Replace category with its frequency.

freq = df['city'].value_counts() / len(df)
df['city_freq'] = df['city'].map(freq)

5.4 TARGET ENCODING
--------------------
Replace category with mean of target for that category.

from category_encoders import TargetEncoder

te = TargetEncoder(cols=['city'])
df['city_target_enc'] = te.fit_transform(df['city'], df['target'])

CAUTION: Can cause data leakage if not done properly!

5.5 LABEL ENCODING
-------------------
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
df['color_encoded'] = le.fit_transform(df['color'])

USE WHEN: tree-based models (they can handle ordinal relationships)
DO NOT USE: linear models (implies false ordering)

6. INTERACTION FEATURES
================================================================================

INTUITION
---------
Some features are more powerful when combined.

df['area'] = df['length'] * df['width']
df['bmi'] = df['weight'] / (df['height'] ** 2)
df['price_per_sqft'] = df['price'] / (df['sqft'] + 1)

USING SKLEARN
-------------
poly = PolynomialFeatures(degree=2, interaction_only=True)
X_interactions = poly.fit_transform(X)

This creates only interaction terms (no squared terms).

7. AGGREGATION FEATURES
================================================================================

For datasets with groups (e.g., customer purchases):

# Per customer aggregations
customer_features = df.groupby('customer_id').agg(
    total_purchases=('amount', 'sum'),
    avg_purchase=('amount', 'mean'),
    purchase_count=('amount', 'count'),
    max_purchase=('amount', 'max'),
    std_purchase=('amount', 'std')
).reset_index()

# Merge back to main dataframe
df = df.merge(customer_features, on='customer_id', how='left')

8. FEATURE SELECTION
================================================================================

WHY SELECT FEATURES?
---------------------
- Reduces overfitting
- Improves training speed
- Removes noise
- Improves interpretability

8.1 FILTER METHODS (Statistical)
----------------------------------
# Correlation with target
correlations = df.corr()['target'].abs().sort_values(ascending=False)
print(correlations)

# Remove highly correlated features (> 0.95)
corr_matrix = df.corr().abs()
upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
to_drop = [col for col in upper.columns if any(upper[col] > 0.95)]
df_reduced = df.drop(columns=to_drop)

8.2 WRAPPER METHODS
--------------------
from sklearn.feature_selection import RFE, RFECV
from sklearn.ensemble import RandomForestClassifier

# Recursive Feature Elimination
model = RandomForestClassifier(n_estimators=100, random_state=42)
rfe = RFE(model, n_features_to_select=10)
rfe.fit(X_train, y_train)
selected = np.array(feature_names)[rfe.support_]

# RFECV with cross-validation
rfecv = RFECV(model, step=1, cv=5, scoring='accuracy')
rfecv.fit(X_train, y_train)
print(f"Optimal features: {rfecv.n_features_}")

8.3 EMBEDDED METHODS
---------------------
# Lasso (L1) feature selection

-----------------------

9. FEATURE ENGINEERING PIPELINE
================================================================================

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.ensemble import RandomForestClassifier

# Define feature types
numerical_features = ['age', 'income', 'score']
categorical_features = ['department', 'city']

# Numerical pipeline
numerical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

# Categorical pipeline
categorical_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='most_frequent')),
    ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
])

# Combine
preprocessor = ColumnTransformer([
    ('num', numerical_pipeline, numerical_features),
    ('cat', categorical_pipeline, categorical_features)
])

# Full pipeline
full_pipeline = Pipeline([
    ('preprocessor', preprocessor),
    ('model', RandomForestClassifier(n_estimators=100, random_state=42))
])

full_pipeline.fit(X_train, y_train)
y_pred = full_pipeline.predict(X_test)

10. COMMON MISTAKES
================================================================================

MISTAKE 1: Feature engineering on test set
  WRONG: Create features on full dataset, then split
  RIGHT: Split first, create features only on training data

MISTAKE 2: Too many polynomial features
  WRONG: PolynomialFeatures(degree=5) → millions of features
  RIGHT: Start with degree 2, use feature selection

MISTAKE 3: Target encoding without cross-validation
  WRONG: df['city'] = df.groupby('city')['target'].mean()
  RIGHT: Use category_encoders.TargetEncoder or cross-validated encoding

MISTAKE 4: Ignoring data leakage in aggregations
  WRONG: Aggregating over entire dataset before splitting
  RIGHT: Aggregate on training data only, apply to test

MISTAKE 5: Not using pipelines
  WRONG: Manual preprocessing → train → predict
  RIGHT: Pipeline ensures consistent, leakage-free preprocessing
