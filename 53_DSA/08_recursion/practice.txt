## EASY (10 Questions)

1. What is recursion?
   Answer: A function that calls itself, breaking the problem into smaller subproblems

2. What is a base case?
   Answer: The condition that stops recursion, preventing infinite calls

3. What is the call stack?
   Answer: The stack that stores function calls; each recursive call pushes a frame

4. What is the time complexity of naive Fibonacci?
   Answer: O(2^n) — exponential, many redundant calculations

5. What is memoization?
   Answer: Caching results of expensive function calls to avoid redundant computation

6. What is the difference between recursion and iteration?
   Answer: Recursion: function calls itself. Iteration: uses loops. Both solve repetitive problems

7. What is tail recursion?
   Answer: When the recursive call is the last operation — allows compiler optimization

8. What is the space complexity of recursion?
   Answer: O(depth) — each call adds a frame to the call stack

9. What is a recursive tree?
   Answer: A visualization of all recursive calls, showing the branching structure

10. What is backtracking?
    Answer: Recursion that explores all possibilities and undoes choices when they don't lead to a solution

11. Factorial using recursion.
    ```python
    def factorial(n):
        if n <= 1: return 1
        return n * factorial(n - 1)
    ```

12. Fibonacci with memoization.
    ```python
    from functools import lru_cache
    @lru_cache(maxsize=None)
    def fib(n):
        if n <= 1: return n
        return fib(n-1) + fib(n-2)
    ```

13. Power function (x^n) in O(log n).
    ```python
    def power(x, n):
        if n == 0: return 1
        half = power(x, n // 2)
        return half * half if n % 2 == 0 else half * half * x
    ```

14. Generate all subsets of a set.
    ```python
    def subsets(nums):
        result = []
        def backtrack(start, current):
            result.append(current[:])
            for i in range(start, len(nums)):
                current.append(nums[i])
                backtrack(i + 1, current)
                current.pop()
        backtrack(0, [])
        return result
    ```

15. Generate all permutations.
    ```python
    def permute(nums):
        result = []
        def backtrack(start):
            if start == len(nums):
                result.append(nums[:])
            for i in range(start, len(nums)):
                nums[start], nums[i] = nums[i], nums[start]
                backtrack(start + 1)
                nums[start], nums[i] = nums[i], nums[start]
        backtrack(0)
        return result
    ```
