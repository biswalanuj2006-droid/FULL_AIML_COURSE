## EASY (10 Questions)

1. What is hashing?
   Answer: Mapping data to fixed-size values using a hash function for O(1) average lookup

2. What is a hash table?
   Answer: A data structure that stores key-value pairs using a hash function to compute an index

3. What is a hash collision?
   Answer: When two different keys produce the same hash value

4. How are hash collisions resolved?
   Answer: Chaining (linked lists at each bucket) or open addressing (linear/quadratic probing)

5. What is the average time complexity of hash table operations?
   Answer: O(1) for search, insert, delete

6. What is the worst-case time complexity?
   Answer: O(n) — when all keys collide into the same bucket

7. What is a hash set?
   Answer: A hash table that stores only keys (no values), used for membership checking

8. What makes a good hash function?
   Answer: Uniform distribution, low collision rate, fast to compute, deterministic

9. What is Python's dictionary?
   Answer: A hash table implementation mapping keys to values

10. What is the time complexity of checking if an element exists in a set?
    Answer: O(1) average

## MEDIUM (15 Questions)

11. Two Sum problem.
    ```python
    def two_sum(nums, target):
        seen = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
    ```

12. Group anagrams.
    ```python
    from collections import defaultdict
    def group_anagrams(strs):
        groups = defaultdict(list)
        for s in strs:
            groups[tuple(sorted(s))].append(s)
        return list(groups.values())
    ```

13. Find the majority element using hashmap.
    ```python
    from collections import Counter
    def majority_element(nums):
        counts = Counter(nums)
        for num, count in counts.items():
            if count > len(nums) // 2:
                return num
    ```

14. Subarray sum equals k.
    ```python
    def subarray_sum(nums, k):
        count = {0: 1}
        prefix = result = 0
        for num in nums:
            prefix += num
            result += count.get(prefix - k, 0)
            count[prefix] = count.get(prefix, 0) + 1
        return result
    ```

15. Longest consecutive sequence (O(n) using set).
    ```python
    def longest_consecutive(nums):
        num_set = set(nums)
        longest = 0
        for num in num_set:
            if num - 1 not in num_set:
                current = num
                while current + 1 in num_set:
                    current += 1
                longest = max(longest, current - num + 1)
        return longest
    ```

16. Find all duplicates in an array.
    ```python
    def find_duplicates(nums):
        count = {}
        duplicates = []
        for num in nums:
            count[num] = count.get(num, 0) + 1
            if count[num] == 2:
                duplicates.append(num)
        return duplicates
    ```
