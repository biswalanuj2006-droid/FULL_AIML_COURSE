## EASY (6 Questions)

1. What is a trie?
   Answer: A tree-like data structure for storing strings, where each node represents a character

2. What is the time complexity of search in a trie?
   Answer: O(m) where m is the length of the search string

3. What is the advantage of a trie over a hash set?
   Answer: Efficient prefix searching, ordered traversal, space sharing for common prefixes

4. What is a prefix tree?
   Answer: Same as trie — a tree where each path from root to node represents a prefix

5. What is the space complexity of a trie?
   Answer: O(ALPHABET_SIZE × N × M) worst case, but much less with shared prefixes

6. What is the use of tries in autocomplete?
   Answer: Given a prefix, traverse the trie to find all words with that prefix

## MEDIUM (10 Questions)

7. Implement a basic trie.
    ```python
    class TrieNode:
        def __init__(self):
            self.children = {}
            self.is_end = False
    class Trie:
        def __init__(self):
            self.root = TrieNode()
        def insert(self, word):
            node = self.root
            for c in word:
                if c not in node.children:
                    node.children[c] = TrieNode()
                node = node.children[c]
            node.is_end = True
        def search(self, word):
            node = self.root
            for c in word:
                if c not in node.children:
                    return False
                node = node.children[c]
            return node.is_end
        def starts_with(self, prefix):
            node = self.root
            for c in prefix:
                if c not in node.children:
                    return False
                node = node.children[c]
            return True
    ```

8. Implement autocomplete using trie.
    ```python
    def autocomplete(trie, prefix):
        node = trie.root
        for c in prefix:
            if c not in node.children:
                return []
            node = node.children[c]
        results = []
        def dfs(node, current):
            if node.is_end:
                results.append(current)
            for c, child in node.children.items():
                dfs(child, current + c)
        dfs(node, prefix)
        return results
    ```
