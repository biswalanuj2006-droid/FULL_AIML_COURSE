## EASY (8 Questions)

1. What is a greedy algorithm?
   Answer: An algorithm that makes the locally optimal choice at each step, hoping to find a global optimum

2. When does greedy work?
   Answer: When the problem has optimal substructure and the greedy choice property (local optimum leads to global optimum)

3. What is the difference between greedy and dynamic programming?
   Answer: Greedy: makes one choice, never reconsiders. DP: considers all subproblems

4. What is the time complexity of activity selection?
   Answer: O(n log n) — dominated by sorting

5. What is interval scheduling?
   Answer: Selecting the maximum number of non-overlapping intervals

6. What is a greedy proof strategy?
   Answer: Exchange argument — show that swapping a greedy choice with any other doesn't improve the solution

7. What is fractional knapsack?
   Answer: Greedy approach where you can take fractions of items — sort by value/weight ratio

8. What is 0/1 knapsack vs fractional knapsack?
   Answer: 0/1: items are indivisible (DP needed). Fractional: items can be split (greedy works)

## MEDIUM (12 Questions)

9. Jump game (can you reach the end?).
    ```python
    def can_jump(nums):
        max_reach = 0
        for i, num in enumerate(nums):
            if i > max_reach: return False
            max_reach = max(max_reach, i + num)
        return True
    ```

10. Jump game II (minimum jumps).
    ```python
    def jump(nums):
        jumps = cur_end = cur_farthest = 0
        for i in range(len(nums) - 1):
            cur_farthest = max(cur_farthest, i + nums[i])
            if i == cur_end:
                jumps += 1
                cur_end = cur_farthest
        return jumps
    ```

11. Activity selection problem.
    ```python
    def activity_selection(activities):
        activities.sort(key=lambda x: x[1])  # Sort by end time
        result = [activities[0]]
        last_end = activities[0][1]
        for start, end in activities[1:]:
            if start >= last_end:
                result.append((start, end))
                last_end = end
        return result
    ```

12. Minimum number of coins (greedy — works for specific coin systems).
    ```python
    def min_coins(coins, amount):
        coins.sort(reverse=True)
        count = 0
        for coin in coins:
            while amount >= coin:
                amount -= coin
                count += 1
        return count if amount == 0 else -1
    ```
