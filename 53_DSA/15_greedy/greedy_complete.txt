1. WHAT IS GREEDY?
================================================================================

INTUITION
---------
Make the locally optimal choice at each step, hoping for a global optimum.

WHEN GREEDY WORKS:
- Greedy choice property: local optimum leads to global optimum
- Optimal substructure: optimal solution contains optimal sub-solutions

WHEN GREEDY FAILS:
- 0/1 Knapsack (need DP)
- When local optimum doesn't lead to global optimum

ACTIVITY SELECTION
-------------------
Given intervals, select maximum non-overlapping activities.

def activity_selection(activities):
    activities.sort(key=lambda x: x[1])  # sort by end time
    result = [activities[0]]
    for i in range(1, len(activities)):
        if activities[i][0] >= result[-1][1]:
            result.append(activities[i])
    return result

FRACTIONAL KNAPSACK
---------------------
def fractional_knapsack(weights, values, capacity):
    items = sorted(zip(values, weights), key=lambda x: x[0]/x[1], reverse=True)
    total = 0
    for val, weight in items:
        if capacity >= weight:
            total += val
            capacity -= weight
        else:
            total += val * (capacity / weight)
            break
    return total

JUMP GAME (LC #55)
--------------------
def canJump(nums):
    max_reach = 0
    for i in range(len(nums)):
        if i > max_reach:
            return False
        max_reach = max(max_reach, i + nums[i])
    return True

PARTITION LABELS (LC #763)
----------------------------
def partitionLabels(s):
    last = {c: i for i, c in enumerate(s)}
    result = []
    start = end = 0
    for i, c in enumerate(s):
        end = max(end, last[c])
        if i == end:
            result.append(end - start + 1)
            start = i + 1
    return result
