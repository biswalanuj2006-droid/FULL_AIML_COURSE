## EASY (10 Questions)

1. What is binary search?
   Answer: An efficient search algorithm that finds target in O(log n) by halving the search space

2. What is the precondition for binary search?
   Answer: The array must be sorted

3. What is the time complexity of binary search?
   Answer: O(log n)

4. What is the space complexity?
   Answer: O(1) iterative, O(log n) recursive (call stack)

5. What is lower bound?
   Answer: The first index where element >= target

6. What is upper bound?
   Answer: The first index where element > target

7. Can binary search be used on unsorted arrays?
   Answer: No — the array must be sorted for the divide-and-conquer property to work

8. What is "binary search on answer"?
   Answer: Binary searching over the solution space (e.g., minimum feasible value) rather than over array indices

9. How many comparisons does binary search make in the worst case?
   Answer: ⌊log₂(n)⌋ + 1

10. What is the difference between binary search and linear search?
    Answer: Binary: O(log n) on sorted data. Linear: O(n) on any data.

## MEDIUM (15 Questions)

11. Standard binary search.
    ```python
    def binary_search(arr, target):
        lo, hi = 0, len(arr) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if arr[mid] == target: return mid
            elif arr[mid] < target: lo = mid + 1
            else: hi = mid - 1
        return -1
    ```

12. Find first occurrence of target.
    ```python
    def first_occurrence(arr, target):
        lo, hi = 0, len(arr) - 1
        result = -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if arr[mid] == target:
                result = mid
                hi = mid - 1  # Continue searching left
            elif arr[mid] < target:
                lo = mid + 1
            else:
                hi = mid - 1
        return result
    ```

        while lo <= hi:

14. Find minimum in rotated sorted array.
    ```python
    def find_min(nums):
        lo, hi = 0, len(nums) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] > nums[hi]:
                lo = mid + 1
            else:
                hi = mid
        return nums[lo]
    ```

15. Search in rotated sorted array.
    ```python
    def search_rotated(nums, target):
        lo, hi = 0, len(nums) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if nums[mid] == target: return mid
            if nums[lo] <= nums[mid]:  # Left half sorted
                if nums[lo] <= target < nums[mid]:
                    hi = mid - 1
                else:
                    lo = mid + 1
            else:  # Right half sorted
                if nums[mid] < target <= nums[hi]:
                    lo = mid + 1
                else:
                    hi = mid - 1
        return -1
    ```

16. Find square root of n (integer part).
    ```python
    def sqrt_int(n):
        if n < 2: return n
        lo, hi = 1, n // 2
        while lo <= hi:
            mid = (lo + hi) // 2
            if mid * mid == n: return mid
            elif mid * mid < n: lo = mid + 1
            else: hi = mid - 1
        return hi
    ```
