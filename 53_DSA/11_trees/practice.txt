## EASY (10 Questions)

1. What is a binary tree?
   Answer: A tree where each node has at most 2 children (left and right)

2. What is a BST (Binary Search Tree)?
   Answer: A binary tree where left child < parent < right child, enabling O(log n) search

3. What is the height of a tree?
   Answer: The number of edges on the longest path from root to leaf

4. What is the difference between depth and height?
   Answer: Depth: distance from root to node. Height: distance from node to deepest leaf

5. What is a leaf node?
   Answer: A node with no children

6. What is the time complexity of search in a balanced BST?
   Answer: O(log n)

7. What is the difference between DFS and BFS?
   Answer: DFS: explores depth first (uses stack/recursion). BFS: explores level by level (uses queue)

8. What are the three DFS traversals?
   Answer: Inorder (Left, Root, Right), Preorder (Root, Left, Right), Postorder (Left, Right, Root)

9. What is the time complexity of tree traversals?
   Answer: O(n) — visit every node once

10. What is a complete binary tree?
    Answer: A binary tree where all levels are filled except possibly the last, which is filled left to right

## MEDIUM (15 Questions)

11. Inorder traversal (iterative using stack).
    ```python
    def inorder(root):
        result, stack = [], []
        while root or stack:
            while root:
                stack.append(root)
                root = root.left
            root = stack.pop()
            result.append(root.val)
            root = root.right
        return result
    ```

12. Level order traversal (BFS).
    ```python
    from collections import deque
    def level_order(root):
        if not root: return []
        result, queue = [], deque([root])
        while queue:
            level = []
            for _ in range(len(queue)):
                node = queue.popleft()
                level.append(node.val)
                if node.left: queue.append(node.left)
                if node.right: queue.append(node.right)
            result.append(level)
        return result
    ```

13. Maximum depth of binary tree.
    ```python
    def max_depth(root):
        if not root: return 0
        return 1 + max(max_depth(root.left), max_depth(root.right))
    ```

14. Validate BST.
    ```python
    def is_valid_bst(root, lo=float('-inf'), hi=float('inf')):
        if not root: return True
        if root.val <= lo or root.val >= hi: return False
        return (is_valid_bst(root.left, lo, root.val) and
                is_valid_bst(root.right, root.val, hi))
    ```

15. Lowest common ancestor of BST.
    ```python
    def lca_bst(root, p, q):
        while root:
            if p.val < root.val and q.val < root.val:
                root = root.left
            elif p.val > root.val and q.val > root.val:
                root = root.right
            else:
                return root
    ```
