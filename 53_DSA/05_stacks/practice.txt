## EASY (10 Questions)

1. What is a stack?
   Answer: LIFO (Last In, First Out) data structure — push and pop from the top

2. What is the time complexity of push and pop?
   Answer: O(1) for both

3. What data structure can be used to implement a stack?
   Answer: Array, linked list, or Python list

4. What is the difference between stack and queue?
   Answer: Stack: LIFO. Queue: FIFO (First In, First Out)

5. What is a monotonic stack?
   Answer: A stack where elements are in strictly increasing or decreasing order

6. What is the use of stacks in function calls?
   Answer: Call stack stores function frames — each call pushes a frame, return pops it

7. What is balanced parentheses?
   Answer: Every opening bracket has a corresponding closing bracket in correct order

8. What is the time complexity of evaluating a postfix expression?
   Answer: O(n) — single pass through the expression

9. What is the difference between postfix and prefix notation?
   Answer: Postfix: operator after operands (2 3 +). Prefix: operator before operands (+ 2 3)

10. What is an undo operation typically implemented with?
    Answer: A stack — each action is pushed; undo pops the last action

## MEDIUM (15 Questions)

11. Valid parentheses checker.
    ```python
    def is_valid(s):
        stack = []
        mapping = {')': '(', ']': '[', '}': '{'}
        for c in s:
            if c in mapping:
                if not stack or stack[-1] != mapping[c]:
                    return False
                stack.pop()
            else:
                stack.append(c)
        return not stack
    ```

12. Next greater element using monotonic stack.
    ```python
    def next_greater(nums):
        n = len(nums)
        result = [-1] * n
        stack = []
        for i in range(n):
            while stack and nums[i] > nums[stack[-1]]:
                result[stack.pop()] = nums[i]
            stack.append(i)
        return result
    ```

13. Min Stack — support push, pop, top, and getMin in O(1).
    ```python
    class MinStack:
        def __init__(self):
            self.stack = []
            self.min_stack = []
        def push(self, val):
            self.stack.append(val)
            val = min(val, self.min_stack[-1] if self.min_stack else val)
            self.min_stack.append(val)
        def pop(self):
            self.stack.pop()
            self.min_stack.pop()
        def top(self):
            return self.stack[-1]
        def getMin(self):
            return self.min_stack[-1]
    ```

14. Evaluate postfix expression.
    ```python
    def eval_rpn(tokens):
        stack = []
        for t in tokens:
            if t in '+-*/':
                b, a = stack.pop(), stack.pop()
                if t == '+': stack.append(a + b)
                elif t == '-': stack.append(a - b)
                elif t == '*': stack.append(a * b)
                else: stack.append(int(a / b))
            else:
                stack.append(int(t))
        return stack[0]
    ```
