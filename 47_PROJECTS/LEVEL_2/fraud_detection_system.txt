PROJECT 4: FRAUD DETECTION SYSTEM (LEVEL 2)
================================================================================

PROBLEM STATEMENT
-----------------
Build a fraud detection system that identifies fraudulent transactions
in real-time from a stream of financial transactions.

GOAL: Handle imbalanced data, build a complete ML pipeline with API.

DATASET
-------
- Source: Kaggle Credit Card Fraud Detection
- Features: V1-V28 (PCA), Amount, Time
- Target: Class (0=legit, 1=fraud)
- Size: ~284,000 transactions
- Imbalance: 0.17% fraud

ARCHITECTURE
------------
Data → EDA → Feature Engineering → Handle Imbalance → Model Training
→ Evaluation → FastAPI Endpoint → Database → Testing

IMPLEMENTATION STEPS
--------------------

1. EDA
   - Class distribution (highly imbalanced)
   - Transaction amount distributions
   - Time patterns
   - Feature correlations

2. PREPROCESSING
   - Scale Amount and Time
   - Handle class imbalance:
     a. SMOTE (oversampling)
     b. Class weights
     c. Undersampling
   - Feature engineering:
     a. Transaction hour
     b. Amount bins
     c. Velocity features

5. API ENDPOINT (FastAPI)
   from fastapi import FastAPI
   import joblib

   app = FastAPI()
   model = joblib.load('fraud_model.pkl')

   @app.post('/predict')
   async def predict(transaction: TransactionSchema):
       features = preprocess(transaction)
       prediction = model.predict([features])
       probability = model.predict_proba([features])
       return {
           'is_fraud': bool(prediction[0]),
           'fraud_probability': float(probability[0][1])
       }

6. DATABASE
   - Store predictions in PostgreSQL
   - Log all predictions for monitoring
   - Alert system for high-confidence fraud
