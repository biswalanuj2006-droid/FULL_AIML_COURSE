PROJECT 2: HOUSE PRICE PREDICTOR (LEVEL 1)
================================================================================

PROBLEM STATEMENT
-----------------
Predict house prices based on features like square footage, bedrooms,
location, and age.

GOAL: Learn regression workflow end-to-end.

DATASET
-------
- Source: Kaggle House Prices / Boston Housing / California Housing
- Features: sqft, bedrooms, bathrooms, location, age, garage
- Target: price
- Size: ~2,000-50,000 samples

ARCHITECTURE
------------
Data → EDA → Preprocessing → Multiple Models → Evaluation → Simple Web UI

IMPLEMENTATION STEPS
--------------------

1. LOAD & EXPLORE
   import pandas as pd
   df = pd.read_csv('house_prices.csv')
   print(df.describe())
   print(df.isnull().sum())

2. EDA
   - Price distribution (histogram)
   - Price vs square footage (scatter)
   - Correlation heatmap
   - Feature importance

3. PREPROCESSING
   - Handle missing values (median imputation)
   - Log transform skewed features
   - One-hot encode categorical features
   - Standardize numerical features
   - Train/test split (80/20)

4. MODEL TRAINING
   from sklearn.linear_model import LinearRegression, Ridge
   from sklearn.ensemble import RandomForestRegressor

   models = {
       'Linear': LinearRegression(),
       'Ridge': Ridge(alpha=1.0),

5. EVALUATION

6. INTERFACE (Streamlit)
   import streamlit as st
   st.title("House Price Predictor")
   sqft = st.number_input("Square Footage", 500, 5000)
   bedrooms = st.slider("Bedrooms", 1, 6)
   # ... more inputs
   if st.predict("Predict"):
       price = model.predict([[sqft, bedrooms, ...]])
       st.write(f"Estimated Price: ${price[0]:,.0f}")
