PROJECT LEVELS
==============

LEVEL 1 — BEGINNER
-------------------
Single model, small dataset, simple interface.
Goal: Learn fundamentals, get comfortable with the workflow.

LEVEL 2 — INTERMEDIATE
-----------------------
Multiple components, real dataset, API, database or advanced preprocessing.
Goal: Build end-to-end systems, handle real-world complexity.

LEVEL 3 — ADVANCED / INDUSTRY
-------------------------------
Production-style architecture, model pipeline, backend, database,
authentication, monitoring, Docker, testing, deployment.
Goal: Build production-ready systems.

================================================================================
PROJECT REQUIREMENTS (ALL LEVELS)
==================================

Every project must include:
1. Problem statement
2. Requirements
3. Architecture diagram
4. Dataset description
5. Implementation code
6. Training & evaluation
7. Visualization
8. README with setup instructions
9. requirements.txt

Level 2+ also requires:
10. API endpoint
11. Database integration
12. Data preprocessing pipeline

Level 3 also requires:
13. Authentication
14. Docker containerization
15. Unit tests
16. CI/CD setup
17. Monitoring
18. Deployment
