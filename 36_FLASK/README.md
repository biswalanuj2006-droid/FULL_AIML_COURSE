# Module 36: Flask

Lightweight, battle-tested Python web framework — useful when you need
simplicity, templates, or to maintain legacy services.

## What You Will Learn

- App structure, routing, request/response objects
- JSON APIs and rendering templates
- Blueprints for modular apps
- Configuration patterns and environment variables
- Authentication basics (sessions, tokens)
- SQLAlchemy integration (cross-ref Module 40)
- Error handling and validation
- Testing Flask apps
- Serving an ML model with Flask
- Flask vs FastAPI: choosing deliberately (comparison table in notes)
