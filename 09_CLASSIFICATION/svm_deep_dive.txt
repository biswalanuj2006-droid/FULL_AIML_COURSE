================================================================================
LESSON: SUPPORT VECTOR MACHINES - DEEP DIVE (primal, dual, KKT, kernels)
================================================================================
Why SVMs still matter in a gradient-boosting world: they are the cleanest
bridge between linear models, convex optimization, and kernel methods,
and the dual formulation is the conceptual ancestor of modern kernel
machines and attention. This file goes to the math. For the applied
overview see classification_complete.txt.

--------------------------------------------------------------------------------
1. THE GEOMETRY (hard-margin SVM)
--------------------------------------------------------------------------------
Binary labels y in {-1, +1}. A linear classifier is a hyperplane
    w . x + b = 0            (w = normal vector, b = offset)
with decision rule  sign(w . x + b).
The MARGIN of a hyperplane w.r.t. a point x with label y is the distance
from x to the plane, signed positive when classified correctly:
    gamma(x, y) = y (w . x + b) / ||w||
The margin of the hyperplane on the whole dataset is the MINIMUM over
training points. The SVM is the hyperplane with the LARGEST minimum
margin:
    maximize_{w,b}  min_i  y_i (w . x_i + b) / ||w||

Rescale freedom: (w, b) can be scaled without changing the decision
boundary. Fix scale by requiring, for the closest points,
    y_i (w . x_i + b) = 1
(the "canonical" hyperplane). Then the margin equals 1/||w|| and the
hard-margin problem becomes the constrained optimization:

    minimize_{w,b}  1/2 ||w||^2
    subject to      y_i (w . x_i + b) >= 1   for all i

The points where the constraint is ACTIVE (equality) are the SUPPORT
VECTORS - the entire classifier depends only on them. Move any other
point and nothing changes; move a support vector and the plane moves.

--------------------------------------------------------------------------------
2. THE PRIMAL, THE LAGRANGIAN, AND THE DUAL
--------------------------------------------------------------------------------
Constraints complicate minimization. Standard trick: Lagrange
multipliers. Attach alpha_i >= 0 to each constraint and form

    L(w, b, alpha) = 1/2 ||w||^2 - sum_i alpha_i [ y_i (w . x_i + b) - 1 ]

For fixed alpha, minimizing over w and b:
    dL/dw = 0  =>  w = sum_i alpha_i y_i x_i          (w is a linear
                                                    combination of DATA)
    dL/db = 0  =>  sum_i alpha_i y_i = 0

Substitute back into L. The terms in w and b cancel and you get the DUAL
problem (a maximization over alpha only):

    maximize_alpha  sum_i alpha_i - 1/2 sum_i sum_j alpha_i alpha_j
                                        y_i y_j (x_i . x_j)
    subject to      alpha_i >= 0,  sum_i alpha_i y_i = 0

KEY FACTS
  1. The data enters ONLY through inner products x_i . x_j. This single
     fact enables the kernel trick (section 5).
  2. The dual is a quadratic program: convex, one global optimum, solved
     by SMO (sequential minimal optimization) in practice.
  3. Complementary slackness (a KKT condition): alpha_i [ y_i (w . x_i
     + b) - 1 ] = 0. So alpha_i > 0 ONLY for support vectors (points on
     the margin or misclassified) - the solution is SPARSE in data.

--------------------------------------------------------------------------------
3. KKT CONDITIONS (the full optimality story)
--------------------------------------------------------------------------------
The KKT conditions are necessary (and here sufficient, since the problem
is convex and Slater's condition holds) for (w*, b*, alpha*) to be
optimal:
  1. Stationarity:   dL/dw = 0, dL/db = 0   (gradients of L vanish)
  2. Primal feas.:   y_i (w . x_i + b) - 1 >= 0
  3. Dual feas.:     alpha_i >= 0
  4. Complementarity: alpha_i (y_i (w . x_i + b) - 1) = 0
Consequence for prediction: the decision function needs only support
vectors:
    f(x) = sign( sum_{i in SV} alpha_i y_i (x_i . x) + b )
b is recovered from any support vector:  b = y_s - w . x_s.

--------------------------------------------------------------------------------
4. SOFT MARGIN (what real data needs)
--------------------------------------------------------------------------------
Hard margins fail when data is not separable. Introduce slack variables
xi_i >= 0 measuring how far a point violates its margin, and a penalty C:

    minimize_{w,b,xi}  1/2 ||w||^2 + C sum_i xi_i
    subject to         y_i (w . x_i + b) >= 1 - xi_i,   xi_i >= 0

C is the regularization knob: large C -> few violations -> narrow margin
(low bias, high variance); small C -> wide margin, more tolerance
(high bias, low variance).
The dual changes only in the box constraint:
    subject to  0 <= alpha_i <= C,   sum_i alpha_i y_i = 0
(Points with alpha_i = C are misclassified or on the wrong side; they
are bounded because a single outlier cannot get unbounded influence.)
EQUIVALENT LOSS VIEW: soft-margin SVM minimizes hinge loss + ridge:
    minimize_w  1/2 ||w||^2 + C sum_i max(0, 1 - y_i (w . x_i + b))
Hinge loss is a convex upper bound on 0/1 loss - this loss view is what
lets you compare SVMs with logistic loss (logistic regression) and
explain why SVM predictions are NOT calibrated probabilities (they are
distances to the plane).

--------------------------------------------------------------------------------
5. THE KERNEL TRICK
--------------------------------------------------------------------------------
The dual uses x_i . x_j. Suppose we map data to a feature space
phi(x) first. The dual would use phi(x_i) . phi(x_j) - but if we can
compute that inner product WITHOUT ever forming phi, we get all the
power of the high-dimensional space at the cost of the original one.
A KERNEL is a function k(x, z) that equals phi(x) . phi(z) for some
(possibly implicit, even infinite-dimensional) phi. For it to be valid,
k must be positive semi-definite (Mercer's condition): for any finite
set of points, the Gram matrix K_ij = k(x_i, x_j) is PSD.
STANDARD KERNELS
  Linear   : k = x . z
  Polynomial: k = (gamma (x . z) + r)^d          (d controls the degree)
  RBF/Gauss: k = exp(-gamma ||x - z||^2)         (gamma = 1/(2 sigma^2))
  Sigmoid  : k = tanh(gamma (x . z) + r)         (only PSD for some params)
RBF intuition: it is an inner product in an INFINITE-dimensional feature
space (each training point becomes a Gaussian bump; the decision surface
is a weighted sum of bumps). RBF with large gamma = wiggly (overfit);
small gamma = smooth.
THE PRICE: kernel SVMs scale badly. Training is roughly O(n^2)-O(n^3)
in data, prediction costs one kernel evaluation per support vector.
For >~100k rows, linear SVM (or SGD on the primal hinge loss) or gradient
boosting is usually the pragmatic choice.

--------------------------------------------------------------------------------
6. SVR (support vector regression)
--------------------------------------------------------------------------------
Regression analog: fit w . x + b within an epsilon-TUBE around y; points
inside the tube cost nothing, points outside are penalized linearly
(epsilon-insensitive loss):
    loss = max(0, |y - f(x)| - epsilon)
The solution is again sparse: only points OUTSIDE the tube are support
vectors. epsilon sets the tolerance (larger epsilon -> sparser, flatter).

--------------------------------------------------------------------------------
7. COMPLEXITY, NUANCES, AND PRACTICE
--------------------------------------------------------------------------------
  - Complexity: training O(n^2)-O(n^3) typical (SMO: ~O(n^2) average);
    prediction O(#SV) kernel evals. #SV can approach n on noisy data.
  - Scaling: SVM is distance-based - ALWAYS standardize features before
    fitting, or the kernel is dominated by large-scale columns.
  - Imbalanced data: the soft-margin is class-agnostic; use class
    weights (penalize the minority class's slack more) or resampling.
  - Calibration: SVM outputs are distances; if you need probabilities,
    fit Platt scaling (logistic regression on the scores) on a held-out
    set.
  - Kernel choice default: RBF with tuned gamma and C; compare with
    linear on high-dimensional sparse data (text) where linear usually
    wins.
  - Interpretability: linear SVM coefficients are interpretable; kernel
    SVMs are not (feature importance needs approximation).
