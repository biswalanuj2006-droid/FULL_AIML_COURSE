# Module 08: Exploratory Data Analysis

Systematically understanding your data before modeling: distributions,
relationships, missingness, and the questions that shape every later choice.

## What You Will Learn

- EDA as a discipline: question → visualize → conclude → next question
- Univariate analysis: distributions, outliers, skew
- Bivariate analysis: correlations, group comparisons
- Missing-data patterns and why they matter
- Time and categorical structure
- EDA for model prep: what to scale/encode/engineer
- Correlation pitfalls: confounding, multicollinearity
- Communicating findings: charts with clear takeaways
