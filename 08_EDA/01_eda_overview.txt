1. WHAT IS EDA?
================================================================================

INTUITION
---------
Before building a house, you inspect the land: soil type, slope,
underground pipes, neighboring structures. EDA is the land inspection
for data science.

DEFINITION
----------
Exploratory Data Analysis is the process of summarizing the main
characteristics of a dataset using statistics and visualizations,
WITHOUT making assumptions before looking at the data.

EDA vs CONFIRMATORY ANALYSIS
-----------------------------
EDA: "Let me see what's in this data" (open-ended)
Confirmatory: "Let me test this specific hypothesis" (targeted)

In ML, EDA comes BEFORE modeling.

================================================================================
2. WHY EDA MATTERS FOR ML
================================================================================

1. DATA QUALITY CHECK
   - Missing values, duplicates, wrong types
   - Without this, your model trains on garbage

2. FEATURE UNDERSTANDING
   - Which features are useful?
   - Which are redundant?
   - What are their distributions?

3. RELATIONSHIP DISCOVERY
   - Which features correlate with the target?
   - Which features correlate with each other? (multicollinearity)

4. ANOMALY DETECTION
   - Outliers that may skew results
   - Data entry errors

5. MODEL SELECTION GUIDANCE
   - Linear relationships → linear models
   - Complex patterns → tree-based or neural networks

================================================================================
3. THE EDA PIPELINE
================================================================================

STEP 1: DATA OVERVIEW
  → Shape, types, memory usage
  → First/last rows
  → Info and describe

STEP 2: DATA QUALITY
  → Missing values
  → Duplicates
  → Data types (correct vs incorrect)
  → Unique values

STEP 3: UNIVARIATE ANALYSIS
  → Distribution of each feature
  → Central tendency and spread
  → Skewness and kurtosis
  → Outliers

STEP 4: BIVARIATE ANALYSIS
  → Feature vs target relationships
  → Feature vs feature correlations
  → Categorical vs numerical interactions

STEP 5: MULTIVARIATE ANALYSIS
  → Pair plots
  → Correlation matrices
  → Feature interactions

STEP 6: INSIGHTS & ACTION ITEMS
  → Which features to keep/drop
  → Which preprocessing is needed
  → Which models might work best

4. FIRST LOOK AT ANY DATASET
================================================================================

import pandas as pd

# Load data
df = pd.read_csv('data.csv')

# === SHAPE ===
print(f"Rows: {df.shape[0]}, Columns: {df.shape[1]}")

# === DATA TYPES ===
print(df.dtypes)

# === FIRST LOOK ===
print(df.head())
print(df.tail())

# === INFO ===
print(df.info())

# === STATISTICS ===
print(df.describe())          # numerical features
print(df.describe(include='object'))  # categorical features

# === MISSING VALUES ===
print(df.isnull().sum())
print(df.isnull().mean() * 100)  # percentage

# === DUPLICATES ===
print(f"Duplicates: {df.duplicated().sum()}")

# === UNIQUE VALUES ===
for col in df.columns:
    print(f"{col}: {df[col].nunique()} unique values")

6. COMMON MISTAKES
================================================================================

MISTAKE 1: Skipping EDA to jump to modeling
  WRONG: Load data → train model → check accuracy
  RIGHT: Load data → EDA → preprocess → model → evaluate

MISTAKE 2: Only looking at summary statistics
  WRONG: df.describe() → done
  RIGHT: Statistics + visualizations + domain knowledge

MISTAKE 3: Ignoring categorical features in EDA
  WRONG: df.describe() (only numerical)
  RIGHT: df.describe(include='all') for comprehensive view

MISTAKE 4: Not documenting findings
  WRONG: Look at data once, remember everything
  RIGHT: Write down findings, create EDA report
