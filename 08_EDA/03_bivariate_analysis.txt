1. WHY BIVARIATE ANALYSIS?
================================================================================

INTUITION
---------
Univariate analysis tells you about individual features.
Bivariate analysis tells you how TWO features relate to each other.

This is critical for ML because:
- Features correlated with the target → useful for prediction
- Features correlated with each other → potential redundancy

2. NUMERICAL vs NUMERICAL

2.1 CORRELATION COEFFICIENTS
-----------------------------
import pandas as pd
import numpy as np

# Pearson (linear relationships)
pearson_corr = df['age'].corr(df['income'])

# Spearman (monotonic, rank-based)
spearman_corr = df['age'].corr(df['income'], method='spearman')

# Kendall (ordinal, small datasets)
kendall_corr = df['age'].corr(df['income'], method='kendall')

INTERPRETING CORRELATION
------------------------
|corr| > 0.7  → strong
|corr| 0.3-0.7 → moderate
|corr| < 0.3  → weak

+1 → perfect positive linear relationship
 0 → no linear relationship
-1 → perfect negative linear relationship

IMPORTANT: Correlation ≠ Causation!

3.4 STATISTICAL TESTS
----------------------
from scipy import stats

# ANOVA (compare means across >2 groups)
groups = [group['salary'].values for name, group in df.groupby('department')]
f_stat, p_value = stats.f_oneway(*groups)
print(f"ANOVA: F={f_stat:.2f}, p={p_value:.4f}")
# p < 0.05 → significant difference between groups

# t-test (compare means across 2 groups)
group1 = df[df['department'] == 'Engineering']['salary']
group2 = df[df['department'] == 'Sales']['salary']
t_stat, p_value = stats.ttest_ind(group1, group2)
print(f"t-test: t={t_stat:.2f}, p={p_value:.4f}")

4. CATEGORICAL vs CATEGORICAL
================================================================================

4.1 CROSS-TABULATION
--------------------
ct = pd.crosstab(df['gender'], df['department'])
print(ct)

# With proportions
ct_pct = pd.crosstab(df['gender'], df['department'], normalize='index')
print(ct_pct)

4.2 CHI-SQUARED TEST
--------------------
from scipy.stats import chi2_contingency

chi2, p_value, dof, expected = chi2_contingency(ct)
print(f"Chi-squared: {chi2:.2f}, p={p_value:.4f}")
# p < 0.05 → variables are dependent (not independent)

4.3 STACKED BAR CHART
----------------------
ct_pct.plot(kind='bar', stacked=True, figsize=(10, 6))

plt.show()

6. COMMON MISTAKES
================================================================================

MISTAKE 1: Assuming correlation means causation
  WRONG: "Ice cream sales cause drowning deaths" (both caused by summer)
  RIGHT: Correlation identifies patterns, not causes

MISTAKE 2: Ignoring non-linear relationships
  WRONG: Only checking Pearson correlation (linear only)
  RIGHT: Also check Spearman, scatter plots for non-linear patterns

MISTAKE 3: Not checking for multicollinearity
  WRONG: Keeping highly correlated features
  RIGHT: Remove one of two features with |corr| > 0.9

MISTAKE 4: Using correlation for categorical data
  WRONG: df['color'].corr(df['size'])
  RIGHT: Use chi-squared test for categorical vs categorical
