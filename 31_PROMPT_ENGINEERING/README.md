# Module 31: Prompt Engineering

Writing instructions that get reliable outputs from LLMs — systematically,
not by trial-and-error vibes.

## What You Will Learn

- What prompting is and is not (it is not model training)
- Basic patterns: zero-shot, few-shot, chain-of-thought
- Structuring prompts: role, task, constraints, output format
- Reliable structured output: JSON mode, schemas, function calling
- Handling ambiguity, and prompt evaluation loops
- Prompt injection risks and basic guardrails
- When prompting is enough vs when you need RAG or fine-tuning
- Testing prompts: golden sets, regression suites
