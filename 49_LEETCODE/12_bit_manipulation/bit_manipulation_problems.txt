   def singleNumber(nums):
       result = 0
       for num in nums:
           result ^= num  # XOR cancels pairs
       return result

2. NUMBER OF 1 BITS (LC #191)
   def hammingWeight(n):
       count = 0
       while n:
           count += 1
           n &= n - 1  # clear lowest set bit
       return count

================================================================================
KEY BIT OPERATIONS
===================
x & (x - 1)    → clear lowest set bit
x & (-x)        → isolate lowest set bit
x ^ x = 0       → self-cancel
x & 0 = 0       → AND with 0
x | 1 = set LSB → set bit
x ^ 1           → toggle bit
(x >> n) & 1    → get nth bit
x << n           → multiply by 2^n
