- Problem asks for "count ways", "minimum/maximum", "is it possible"
- Overlapping subproblems exist
- Optimal substructure exists

1. CLIMBING STAIRS (LC #70)
   Ways to reach step n (1 or 2 steps at a time).
   dp[i] = dp[i-1] + dp[i-2]
   def climbStairs(n):
       if n <= 2: return n
       a, b = 1, 2
       for _ in range(3, n + 1): a, b = b, a + b
       return b

2. HOUSE ROBBER (LC #198)
   Maximum money without robbing adjacent houses.
   dp[i] = max(dp[i-1], dp[i-2] + nums[i])
   def rob(nums):
       a, b = 0, 0
       for num in nums:
           a, b = b, max(b, a + num)
       return b

3. MAXIMUM SUBARRAY (LC #53)
   Kadane's algorithm.
   def maxSubArray(nums):
       current = global_max = nums[0]
       for num in nums[1:]:
           current = max(num, current + num)
           global_max = max(global_max, current)
       return global_max

4. BEST TIME TO BUY/SELL STOCK (LC #121)
   def maxProfit(prices):
       min_price = float('inf')
       max_profit = 0
       for price in prices:
           min_price = min(min_price, price)
           max_profit = max(max_profit, price - min_price)
       return max_profit

11. COIN CHANGE (LC #322)
    def coinChange(coins, amount):
        dp = [float('inf')] * (amount + 1)
        dp[0] = 0
        for i in range(1, amount + 1):
            for coin in coins:
                if coin <= i:
                    dp[i] = min(dp[i], dp[i - coin] + 1)
        return dp[amount] if dp[amount] != float('inf') else -1

12. LONGEST INCREASING SUBSEQUENCE (LC #300)
    def lengthOfLIS(nums):
        dp = [1] * len(nums)
        for i in range(1, len(nums)):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)

13. LONGEST COMMON SUBSEQUENCE (LC #1143)
    def longestCommonSubsequence(text1, text2):
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        return dp[m][n]

21. EDIT DISTANCE (LC #72)
    def minDistance(word1, word2):
        m, n = len(word1), len(word2)
        dp = [[0] * (n+1) for _ in range(m+1)]
        for i in range(m+1): dp[i][0] = i
        for j in range(n+1): dp[0][j] = j
        for i in range(1, m+1):
            for j in range(1, n+1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
        return dp[m][n]

DP SOLVING CHECKLIST
=====================
1. What does dp[i] represent?
2. What is the base case?
3. What is the recurrence relation?
4. Can I optimize space from O(n²) to O(n)?
5. What is the answer in the dp table?
