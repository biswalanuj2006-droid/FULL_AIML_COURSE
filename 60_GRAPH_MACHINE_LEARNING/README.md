# Module 60: Graph Machine Learning

Learning over relational data - social graphs, molecules, knowledge
graphs - from the adjacency matrix to message-passing GNNs and graph
RAG.

## What You Will Learn

- Graph representations: adjacency, Laplacian, smoothness (x^T L x)
- Shallow node embeddings: DeepWalk / node2vec (walks = sentences)
- Message passing: the one template behind all GNNs
- GCN derivation (normalized adjacency), GAT attention, GraphSAGE
- Why GNNs are shallow: over-smoothing and neighborhood explosion
- Node classification, link prediction, graph classification
- Scaling: neighbor sampling, Cluster-GCN, decoupled propagation
- Knowledge graphs and Graph RAG (relation-based retrieval)

## Code Examples (verified by execution)

| File | What it shows | Result |
|------|---------------|--------|
| code/graph/01_gcn_numpy.py | 2-layer GCN on a synthetic graph (numpy autodiff-free backprop) | 94.2% accuracy vs 50% majority baseline |
| code/graph/02_link_prediction.py | Train/test split that avoids leakage; node-embedding dot-product scoring | ROC-AUC > 0.9 on held-out edges |

Both run with numpy only: `python code/graph/0X_*.py`. The GCN file
documents the classic missing-`Ahat.T` gradient bug the run exposed; the
link-prediction file explains why splitting edges naively leaks.

diagrams/generate_module_diagrams.py).
