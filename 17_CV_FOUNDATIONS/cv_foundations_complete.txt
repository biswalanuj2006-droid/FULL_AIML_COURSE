## WHAT IS COMPUTER VISION?

Computer Vision (CV) is a field of AI that enables machines to interpret and understand visual information from the world — images, videos, and 3D scenes.

### Why It Matters

Every day, humans process enormous amounts of visual data effortlessly. We recognize faces, read text, navigate roads, and detect anomalies — all through vision. Computer Vision aims to replicate this ability in machines.

### The Three Stages of Vision

```
Perception → Understanding → Action
  (seeing)    (interpreting)  (deciding)
```

## PART 1: IMAGE FUNDAMENTALS

### 1.1 How Computers Represent Images

An image is a matrix of numbers (pixels).

```python
import numpy as np

# Grayscale image: 2D array (height × width)
gray_image = np.random.randint(0, 256, size=(480, 640))  # H × W
print(gray_image.shape)  # (480, 640)

# Color image: 3D array (height × width × channels)
color_image = np.random.randint(0, 256, size=(480, 640, 3))  # H × W × C
print(color_image.shape)  # (480, 640, 3)
```

### 1.2 Pixel Values

- Grayscale: 0 (black) to 255 (white)
- Color: Three channels (R, G, B), each 0–255

```python
# Pixel at row 100, column 200
pixel = color_image[100, 200, :]  # [R, G, B]
print(pixel)  # e.g., [234, 12, 67]
```

### 1.3 Color Spaces

| Color Space | Components | Use Case |
|-------------|------------|----------|
| RGB | Red, Green, Blue | Display, deep learning |
| BGR | Blue, Green, Red | OpenCV default |
| HSV | Hue, Saturation, Value | Color-based segmentation |
| Grayscale | Intensity only | Edge detection, preprocessing |
| LAB | Lightness, A-channel, B-channel | Color constancy |
| YCbCr | Luminance, Chrominance | Video compression |

## PART 3: FILTERING AND CONVOLUTION

### 3.1 What is a Filter/Kernel?

A filter (kernel) is a small matrix that slides across the image and computes a new value at each position.

```
Image:               Kernel:
┌─────────────────┐  ┌─────┐
│ 1 2 3 4 5 6 7 8│  │ 1 0 │
│ 9 10 11 12 13  │  │ 0-1 │
│ ...             │  └─────┘
└─────────────────┘
```

### 3.2 Smoothing (Blur)

```python
# Average blur (box filter)
blur_avg = cv2.blur(img, (5, 5))

# Gaussian blur (weighted average)
blur_gauss = cv2.GaussianBlur(img, (5, 5), sigmaX=1.5)

# Median blur (good for salt-and-pepper noise)
blur_median = cv2.medianBlur(img, 5)

# Bilateral filter (preserves edges)
blur_bilateral = cv2.bilateralFilter(img, 9, 75, 75)
```

### 3.3 Edge Detection

```python
# Sobel edges
sobel_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
sobel_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
sobel_mag = np.sqrt(sobel_x**2 + sobel_y**2)

# Canny edge detection (most popular)
edges = cv2.Canny(gray, threshold1=50, threshold2=150)

# Laplacian
laplacian = cv2.Laplacian(gray, cv2.CV_64F)
```

### 3.4 Morphological Operations

```python
kernel = np.ones((5, 5), np.uint8)

# Erosion: shrinks bright regions
eroded = cv2.erode(img_binary, kernel, iterations=1)

# Dilation: expands bright regions
dilated = cv2.dilate(img_binary, kernel, iterations=1)

# Opening: erosion → dilation (removes small noise)
opening = cv2.morphologyEx(img_binary, cv2.MORPH_OPEN, kernel)

# Closing: dilation → erosion (fills small holes)
closing = cv2.morphologyEx(img_binary, cv2.MORPH_CLOSE, kernel)
```

## PART 4: THRESHOLDING

### 4.1 Types

```python
# Simple threshold
_, thresh_simple = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# Otsu's auto-threshold
_, thresh_otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# Adaptive threshold (good for varying lighting)
thresh_adaptive = cv2.adaptiveThreshold(
    gray, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 11, 2
)
```

### 4.2 When to Use Each

| Method | Best For |
|--------|----------|
| Simple | Uniform lighting |
| Otsu | Bimodal histogram |
| Adaptive | Uneven lighting |

### 5.4 Feature Matching

```python
# BFMatcher for SIFT/ORB
bf = cv2.BFMatcher(cv2.NORM_L2, crossCheck=True)
matches = bf.match(desc1, desc2)
```

```python
lower_red2 = np.array([170, 100, 100])
upper_red2 = np.array([180, 255, 255])
mask2 = cv2.inRange(hsv, lower_red2, upper_red2)

mask = mask1 | mask2
red_objects = cv2.bitwise_and(img, img, mask=mask)
```

## CV FOUNDATIONS — ALGORITHM LIBRARY

### Sobel Operator

**Purpose:** Edge detection by computing image gradients

**Kernel X:**
```
-1  0  1
-2  0  2
-1  0  1
```

**Kernel Y:**
```
-1 -2 -1
 0  0  0
 1  2  1
```

**Formula:** G = √(Gx² + Gy²)

**Edge magnitude:** High values indicate edges

### Canny Edge Detection

**Steps:**
1. Gaussian smoothing
2. Compute gradients (Sobel)
3. Non-maximum suppression
4. Double thresholding
5. Edge tracking by hysteresis

### Hough Transform (Lines)

**Purpose:** Detect lines in edge images

**Parameter space:** (ρ, θ) where ρ = x·cos(θ) + y·sin(θ)

**Voting:** Each edge point votes for all possible lines. Peaks in accumulator = detected lines.
