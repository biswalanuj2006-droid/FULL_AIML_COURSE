# Module 48: Capstone Projects

Final, portfolio-grade projects combining everything: data, ML/DL, backend,
databases, deployment, monitoring, and documentation.

## Capstone Options

See `capstone_projects.txt` for the full project specifications (requirements,
architecture, datasets, deliverables, grading rubrics). Options include:

1. Production ML prediction platform (regression/classification API)
2. Deep learning / CV or NLP system with training + deployment
3. Production RAG / LLM application with auth + vector DB
4. Real-time AI system (streaming data + inference + storage)
5. Research capstone: reproduce + improve a published result

## What Each Capstone Requires

- Architecture diagram + tech decisions with rationale
- Trained, evaluated, and tracked model (MLflow-style logs)
- REST API with auth, validation, tests, and docs
- Database-backed storage of inputs/predictions
- Dockerized deployment with health checks
- Monitoring + drift plan and a rollback story
- README, dataset documentation, and an honest limitations section

## Prerequisites

- All core modules; specifically 34, 35, 40, 41, 43
- 50_INTERVIEW_PREP uses these projects in your portfolio

## Exit Criteria

- [ ] One capstone fully complete to the rubric
- [ ] It is live (local or cloud) and demoable
- [ ] You can defend every architecture decision
