## SELF-ASSESSMENT (15 Questions)

1. Rate your Python proficiency (1-10).
   - 1-3: Beginner → Start with 01_PYTHON
   - 4-6: Intermediate → Review 01_PYTHON, start 02_NUMPY
   - 7-8: Advanced → Start 05_MATHEMATICS + 06_ML_FUNDAMENTALS
   - 9-10: Expert → Start 06_ML_FUNDAMENTALS + 07_DATA_PREPROCESSING

2. Can you write functions, loops, and classes in Python?
   - Yes → Proceed to NumPy
   - No → Start 01_PYTHON

3. Do you understand basic statistics (mean, median, standard deviation)?
   - Yes → Proceed to ML Fundamentals
   - No → Start 05_MATHEMATICS

4. Have you used any ML libraries before?
   - Yes → Identify your level and skip ahead
   - No → Follow the course in order

5. What is your learning goal?
   - Get a job in AI/ML → Focus on projects + interview prep
   - Build AI applications → Focus on DL + NLP + GenAI

6. How much time can you dedicate daily?
   - 1 hour → Focus on core modules

   - 4+ hours → Full course + DSA + LeetCode

7. What is your math background?
   - High school → Start 05_MATHEMATICS

8. Do you have a GPU available?

9. Are you comfortable with command line?
