# Module 00: Orientation

Start here. This module tells you how the whole course works, what the roadmap
is, and where you currently stand.

## What You Will Learn

- How the course is structured and how to use it (`how_to_use.txt`)
- The complete learning path (`course_overview.txt`)
- Setup of Python, VS Code, and required libraries (`setup_guide.txt`)
- Your current skill level via the diagnostic assessment
- Your skill level answers/explanations (attempt first, then check)

## Module Files

| File | Purpose |
|------|---------|
| course_overview.txt | What this course is and how modules connect |
| how_to_use.txt | How to study, practice, and do projects |
| setup_guide.txt | Environment setup (Python, venv, libraries) |
| diagnostic_assessment.txt | 40-question placement test |
| diagnostic_answers.txt | Answers with explanations |
| practice.txt | Orientation exercises |

## Prerequisites

- A computer with Python 3.10+ installed
- Motivation to spend ~30-60 minutes reading before touching code

## Exit Criteria

- [ ] You can explain the module roadmap in one paragraph
- [ ] Your environment runs `python --version` and `pip list`
- [ ] You know your diagnostic result and which modules to focus on
