SECTION D: ML CONCEPTS
================================================================================

D1: b) Systems that learn patterns from data to make predictions
    Explanation: ML is about finding patterns in data without being
    explicitly programmed with rules.

D2: b) Input features AND labels/targets
    Explanation: Supervised learning requires labeled data — each training
    example has input features and a known correct output (label/target).

D3: c) High training accuracy, low test accuracy
    Explanation: Overfitting means the model memorized the training data
    but cannot generalize to new, unseen data.

D4: b) Underfitting
    Explanation: High bias = model is too simple to capture the pattern.
    Low variance = model is consistent but consistently wrong.
    This is underfitting.

D5: b) To evaluate how well the model generalizes to unseen data
    Explanation: The test set simulates real-world data the model has never
    seen. It measures generalization ability.

D6: b) Regression, Classification
    Explanation: House prices are continuous values → Regression.
    Spam/not-spam is discrete categories → Classification.

D7: b) Features with larger ranges dominate distance calculations
    Explanation: KNN and SVM use distance metrics. If one feature ranges
    0-1000 and another 0-1, the first feature dominates the distance.
    Scaling puts features on equal footing.

D8: b) Splitting data into 5 parts, using each part as test set once
    Explanation: 5-fold CV divides data into 5 equal parts (folds).
    Each fold is used as the test set exactly once, while the other
    4 folds are used for training. Results are averaged.

D9: b) Model predicted positive, but it was actually negative
    Explanation: "False" = incorrect prediction. "Positive" = predicted class.
    False Positive = predicted positive, actually negative (Type I error).

D10: b) Measure how wrong the model's predictions are
    Explanation: A loss function quantifies the error between predicted
    and actual values. Lower loss = better predictions. Training minimizes
    the loss function.
