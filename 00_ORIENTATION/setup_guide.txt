================================================================================
                     AI/ML ENGINEERING COURSE
                     ENVIRONMENT SETUP GUIDE
================================================================================

This guide helps you set up everything needed for the course.

================================================================================
1. PYTHON INSTALLATION
================================================================================

RECOMMENDED: Python 3.10 or 3.11

WINDOWS:
    1. Visit https://www.python.org/downloads/
    2. Download Python 3.11 (or 3.10)
    3. Run installer
    4. CHECK THE BOX: "Add Python to PATH" ← CRITICAL
    5. Click "Install Now"
    6. Verify: Open terminal and type:
       python --version
       pip --version

MAC:
    1. Visit https://www.python.org/downloads/
    2. Download and install
    3. Or use Homebrew:
       brew install python@3.11

LINUX:
    sudo apt update
    sudo apt install python3.11 python3.11-venv python3-pip

================================================================================
2. VIRTUAL ENVIRONMENT
================================================================================

Always use a virtual environment. It keeps your project dependencies isolated.

CREATE:
    python -m venv ml_course_env

ACTIVATE:
    Windows:   ml_course_env\Scripts\activate
    Mac/Linux: source ml_course_env/bin/activate

DEACTIVATE:
    deactivate

You should see (ml_course_env) in your terminal prompt when activated.

9. GPU SETUP (Optional, for Deep Learning modules)
================================================================================

NVIDIA GPU USERS:

1. Install NVIDIA drivers:
   https://www.nvidia.com/Download/index.aspx

2. Install CUDA Toolkit:
   https://developer.nvidia.com/cuda-toolkit
   Recommended: CUDA 11.8 or 12.1

3. Install cuDNN:
   https://developer.nvidia.com/cudnn

4. Install PyTorch with CUDA:
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

5. Verify GPU in Python:
   import torch
   print(torch.cuda.is_available())
   print(torch.cuda.get_device_name(0))

NOTE: You can complete MOST of the course without a GPU.
      GPU is needed mainly for:
      - Training deep neural networks (Module 18+)
      - Training CNNs (Module 20)
      - Fine-tuning transformers (Module 32)
      - Large-scale NLP experiments

ALTERNATIVE: Google Colab provides free GPU access.
    https://colab.research.google.com/

10. ENVIRONMENT VARIABLES
================================================================================

Some modules require API keys. NEVER commit real keys to Git.

Create a .env file in your project root:

    # .env (NEVER commit this file)
    OPENAI_API_KEY=your_key_here
    HUGGINGFACE_TOKEN=your_token_here
    DATABASE_URL=postgresql://user:password@localhost/dbname
    SECRET_KEY=your_secret_key_here

Add .env to .gitignore:

    # .gitignore
    .env
    __pycache__/
    *.pyc
    .venv/
    ml_course_env/

Load .env in Python:
    pip install python-dotenv

    from dotenv import load_dotenv
    import os
    load_dotenv()
    api_key = os.getenv("OPENAI_API_KEY")

================================================================================
12. TROUBLESHOOTING
================================================================================

PROBLEM: "python" command not found
SOLUTION: Python is not in PATH. Reinstall with "Add to PATH" checked.

PROBLEM: "pip" command not found
SOLUTION: python -m pip install --upgrade pip

PROBLEM: Permission denied on pip install
SOLUTION: Use pip install --user <package> or use a virtual environment

PROBLEM: Import errors
SOLUTION: Make sure your virtual environment is activated.

PROBLEM: Matplotlib plots don't show
SOLUTION: Add matplotlib.use('Agg') or use plt.show() in scripts.
          In Jupyter, use %matplotlib inline.

PROBLEM: CUDA not found
SOLUTION: Install NVIDIA drivers and CUDA toolkit.
          Or use CPU-only PyTorch.
