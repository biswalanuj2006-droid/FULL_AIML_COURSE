## PROJECT 1 — MNIST DIGIT CLASSIFIER (Level 1)

### Problem Statement
Build a neural network to classify handwritten digits.

### Requirements
- Load MNIST dataset
- Build 2-layer neural network from scratch (NumPy)
- Train with gradient descent
- Implement backpropagation

### Expected Output
- Training loss curve
- Accuracy > 95%
- Confusion matrix

## PROJECT 2 — CIFAR-10 IMAGE CLASSIFIER (Level 2)

### Problem Statement
Build a CNN for image classification on CIFAR-10.

### Requirements
- Load CIFAR-10 dataset
- Build CNN from scratch (PyTorch)
- Implement data augmentation
- Train with batch normalization and dropout
- Use learning rate scheduling
- Evaluate per-class metrics
- Save/load model checkpoints

### Architecture
```
Input (3×32×32)
→ Conv(32) → BN → ReLU → Pool
→ Conv(64) → BN → ReLU → Pool
→ Conv(128) → BN → ReLU → Pool
→ Flatten → Dense(128) → Dropout → Dense(10)
```

### Expected Output
- Training/validation curves
- Per-class accuracy
- Confusion matrix
- Saved model
