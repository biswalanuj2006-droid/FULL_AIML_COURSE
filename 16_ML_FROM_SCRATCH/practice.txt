## THEORY QUESTIONS (10 Questions)

21. Why implement ML algorithms from scratch?
    Answer: Deep understanding of internals, better debugging, ability to customize

22. What are the limitations of from-scratch implementations?
    Answer: Not optimized, missing edge cases, no GPU support, less tested

23. When would you use from-scratch vs library?
    Answer: Learning/custom research → from-scratch. Production → library.

24. What is the most important thing to verify in from-scratch implementations?
    Answer: Correctness — compare output with established library on same input

25. How do you handle numerical stability in from-scratch implementations?
    Answer: Clip values, add epsilon to denominators, use stable algorithms

26. What is vectorization and why is it important?
    Answer: Replacing loops with matrix operations — much faster in NumPy

27. How do you test ML implementations?
    Answer: Unit tests for components, integration tests on known datasets, comparison with library

28. What are common bugs in ML implementations?
    Answer: Off-by-one errors, wrong gradient formulas, forgetting to normalize, data leakage

29. How do you optimize from-scratch implementations?
    Answer: Vectorize with NumPy, minimize memory allocation, use efficient algorithms

30. What is the value of implementing from scratch vs using library?
    Answer: From scratch builds understanding; library builds production capability. Both are important.
