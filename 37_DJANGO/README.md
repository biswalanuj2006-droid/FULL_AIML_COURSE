# Module 37: Django

Full-featured web framework with ORM, admin, and auth built in — the right
choice for data-heavy web products and internal ML platforms.

## What You Will Learn

- Project/app structure, URLs, views, templates
- Models and the ORM; migrations
- Django admin and why it accelerates internal tools
- Authentication and permissions
- Django REST Framework: serializers, viewsets, routers
- PostgreSQL integration
- Serving AI features inside a real web app
- Testing Django views and APIs
- Deployment basics (collectstatic, gunicorn, Docker)
