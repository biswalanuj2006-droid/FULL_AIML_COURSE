# Module 38: REST APIs & HTTP

The language every AI service speaks: HTTP semantics, REST design, and the
contracts between models, backends, and clients.

## What You Will Learn

- HTTP: methods, status codes, headers, semantics
- JSON as the data contract
- REST principles: resources, URLs, idempotency
- Request/response design; error formats
- Pagination, filtering, and versioning APIs
- REST vs GraphQL vs WebSocket (when each fits)
- Client-side: requests/httpx with timeouts, retries, auth
- API documentation (OpenAPI) and why it matters
- Building your first API with FastAPI/Flask (Modules 35-36)
