# Module 06: Machine Learning Fundamentals

The conceptual bridge between data and models: what ML is, how learning
happens, and the vocabulary every later module assumes you know.

## What You Will Learn

- AI vs ML vs DL; supervised vs unsupervised vs RL
- Features, labels, training/validation/test
- The learning problem: parameters, loss, optimization
- Generalization, overfitting, underfitting, bias-variance
- Model capacity, regularization intuition
- Data leakage and why it silently ruins models
- A practical scikit-learn deep dive (main estimators + pipelines)

## Prerequisites

- 01-05 (Python, NumPy basics, and comfort with math notation)
- You do NOT need calculus mastery yet

## Exit Criteria

- [ ] You can explain overfitting to a non-technical person
- [ ] You can list the three data splits and why each exists
- [ ] You can spot a data-leakage trap in a description of a pipeline
- [ ] You can run a basic sklearn model with a train/test split
