# Module 40: Databases for AI Systems

Where your data and predictions live: SQL, NoSQL, and the design skills an
AI engineer actually needs (plus vector DB cross-reference).

## What You Will Learn

- Relational modeling: tables, keys, constraints, normalization
- SQL: SELECT, JOIN, GROUP BY, window functions, subqueries
- Indexes and query performance intuition
- Transactions and ACID
- PostgreSQL deep dive: JSONB, full-text search, pgvector
- SQLite for local/dev; MySQL overview
- NoSQL concepts: document stores (MongoDB), when they fit
- Caching with Redis: patterns, TTL, rate limiting
- Choosing a database for your AI product
- Storing features, predictions, and experiment metadata
