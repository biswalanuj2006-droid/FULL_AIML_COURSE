1. WHY SEABORN?
================================================================================

Seaborn builds on Matplotlib and provides:
- Beautiful default styles
- Statistical visualizations
- Easy creation of complex plots
- Integration with Pandas DataFrames

    import seaborn as sns
    import matplotlib.pyplot as plt

================================================================================
2. DISTRIBUTION PLOTS
================================================================================

    # Histogram with density curve
    sns.histplot(data=df, x="age", kde=True)

    # KDE (Kernel Density Estimation)
    sns.kdeplot(data=df, x="age", hue="churn", fill=True)

    # Rug plot
    sns.rugplot(data=df, x="age")

    ML USE: Understanding feature distributions

================================================================================
3. CATEGORICAL PLOTS
================================================================================

    # Box plot
    sns.boxplot(data=df, x="department", y="salary")

    # Violin plot (box + KDE)
    sns.violinplot(data=df, x="department", y="salary", inner="box")

    # Strip plot (individual points)
    sns.stripplot(data=df, x="department", y="salary", alpha=0.5)

    # Swarm plot (non-overlapping points)
    sns.swarmplot(data=df, x="department", y="salary")

    # Count plot
    sns.countplot(data=df, x="churn")

    # Bar plot with confidence interval
    sns.barplot(data=df, x="department", y="salary", ci=95)

    ML USE: Comparing distributions across categories

================================================================================
4. RELATIONSHIP PLOTS
================================================================================

    # Scatter plot with regression line
    sns.lmplot(data=df, x="age", y="income", hue="churn")

    # Scatter plot matrix
    sns.pairplot(df[["age", "income", "tenure", "churn"]],
                 hue="churn", diag_kind="kde")

    ML USE: Feature relationships, detecting patterns
