# Module 04: Data Visualization

## What You Will Learn

- Matplotlib fundamentals and advanced plots
- Seaborn statistical visualizations
- Plotly interactive charts
- ML-specific visualizations (confusion matrices, ROC curves, etc.)
- Choosing the right chart type

## Why You Need It

Visualization is how you communicate data insights, present model results, and debug ML systems. Every EDA, every model evaluation, every presentation requires strong visualization skills. You cannot do ML without visualization.

## Prerequisites

- Module 01: Python for AI/ML
- Module 02: NumPy
- Module 03: Pandas

## What You Will Be Able to Do After This Module

1. Create publication-quality plots with Matplotlib
2. Build statistical visualizations with Seaborn
3. Create interactive charts with Plotly
4. Visualize ML-specific outputs (confusion matrices, ROC curves, etc.)
5. Choose appropriate chart types for different data
