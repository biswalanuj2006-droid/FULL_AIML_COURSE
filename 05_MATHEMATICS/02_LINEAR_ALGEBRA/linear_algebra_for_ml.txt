2. VECTORS
================================================================================

WHAT IS A VECTOR?
    An ordered list of numbers. Think of it as a POINT in space.

    Feature vector for a person:
    x = [age, income, credit_score]
    x = [25, 50000, 720]

    This person is a POINT in 3-dimensional space.

NOTATION:
    Row vector:    x = [x₁, x₂, x₃]
    Column vector: x = [x₁]    (x is n×1 matrix)
                       [x₂]
                       [x₃]

    In ML, we usually treat vectors as column vectors.

DIMENSION:
    A vector in ℝⁿ has n dimensions.

    x = [1, 2, 3]           → 3-dimensional vector
    y = [0.5, 0.3, 0.2, 0.1] → 4-dimensional vector

    ML USE:
    - Word embeddings are high-dimensional vectors (e.g., 300-dim)
    - Each data sample is a feature vector
    - Model weights are vectors

VECTOR OPERATIONS:

    Vector Addition:
    a = [1, 2, 3]
    b = [4, 5, 6]
    a + b = [5, 7, 9]

    Scalar Multiplication:
    a = [1, 2, 3]
    2a = [2, 4, 6]

    ML USE: Combining features, adding bias

3. DOT PRODUCT
================================================================================

WHAT IS THE DOT PRODUCT?
    The dot product measures how similar two vectors are.

    a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ

    EXAMPLE:
    a = [1, 2, 3]
    b = [4, 5, 6]
    a · b = (1×4) + (2×5) + (3×6) = 4 + 10 + 18 = 32

GEOMETRIC INTERPRETATION:
    a · b = |a| × |b| × cos(θ)

    where θ is the angle between a and b.

    If θ = 0° (same direction): a · b = |a| × |b| (maximum positive)
    If θ = 90° (perpendicular): a · b = 0
    If θ = 180° (opposite):     a · b = -|a| × |b| (maximum negative)

    The dot product measures ALIGNMENT between vectors.

ML USE CASES:

1. LINEAR COMBINATION:
   z = w · x + b = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

   This is the CORE operation in:
   - Linear regression
   - Logistic regression
   - Neural network layers
   - Attention mechanism

2. COSINE SIMILARITY:
   similarity = (a · b) / (|a| × |b|)

   Range: -1 to 1
   1 = identical direction
   0 = perpendicular
   -1 = opposite direction

   ML USE: Comparing word embeddings, document similarity,
   recommendation systems

3. ATTENTION MECHANISM:
   score = query · key

   In transformers, attention scores are dot products between
   query and key vectors.

================================================================================
4. NORMS
================================================================================

A NORM measures the "size" or "magnitude" of a vector.

EUCLIDEAN NORM (L2 Norm):
    ||x||₂ = √(x₁² + x₂² + ... + xₙ²)

    x = [3, 4]
    ||x||₂ = √(9 + 16) = √25 = 5

    Geometric meaning: Distance from origin to the point.

    ML USE: L2 regularization (Ridge regression)
    penalty = ||w||₂² = w₁² + w₂² + ... + wₙ²

MANHATTAN NORM (L1 Norm):
    ||x||₁ = |x₁| + |x₂| + ... + |xₙ|

    x = [3, -4]
    ||x||₁ = 3 + 4 = 7

    Geometric meaning: "Taxicab distance" — distance along axes.

    ML USE: L1 regularization (Lasso regression)
    penalty = ||w||₁ = |w₁| + |w₂| + ... + |wₙ|

    L1 regularization drives some weights to EXACTLY zero
    (feature selection).

REGULARIZATION COMPARISON:
    ┌──────────┬──────────────────────┬────────────────────┐
    │  Norm    │  Formula             │  Effect            │
    ├──────────┼──────────────────────┼────────────────────┤
    │  L1      │  Σ|wᵢ|              │  Sparse weights    │
    │  L2      │  Σwᵢ²               │  Small weights     │
    │  Elastic │  αL1 + βL2          │  Both effects      │
    └──────────┴──────────────────────┴────────────────────┘

================================================================================
5. MATRICES
================================================================================

WHAT IS A MATRIX?
    A rectangular grid of numbers arranged in rows and columns.

    A = │ 1  2  3 │   (2 rows, 3 columns → 2×3 matrix)
        │ 4  5  6 │

    ML USE:
    - Dataset matrix X: rows = samples, columns = features
    - Weight matrix W: rows = output units, columns = input units
    - Covariance matrix: feature relationships

DIMENSIONS:
    A: (m, n) means m rows, n columns

    X: (1000, 10) → 1000 samples, 10 features
    W: (10, 5)    → 10 input features, 5 output units

MATRIX TRANSPOSE:
    A = │ 1  2  3 │      Aᵀ = │ 1  4 │
        │ 4  5  6 │           │ 2  5 │
                               │ 3  6 │

    (m×n)ᵀ = (n×m)
    Rows become columns, columns become rows.

    ML USE:
    X: (n_samples, n_features)
    X.T: (n_features, n_samples)

    For computing covariance: C = (1/n) XᵀX

IDENTITY MATRIX:
    I = │ 1  0  0 │
        │ 0  1  0 │
        │ 0  0  1 │

    A × I = A (multiplying by identity doesn't change anything)
    Like multiplying by 1 in regular arithmetic.

================================================================================
6. MATRIX MULTIPLICATION
================================================================================

RULES:
    A: (m, k) × B: (k, n) = C: (m, n)
    Inner dimensions must match!

    To compute element C[i][j]:
    C[i][j] = Σₖ A[i][k] × B[k][j]
    (dot product of row i of A with column j of B)

EXAMPLE:
    A = │ 1  2 │    B = │ 5  6 │
        │ 3  4 │        │ 7  8 │

    C[0][0] = (1×5) + (2×7) = 19
    C[0][1] = (1×6) + (2×8) = 22
    C[1][0] = (3×5) + (4×7) = 43
    C[1][1] = (3×6) + (4×8) = 50

    C = │ 19  22 │
        │ 43  50 │

ML USE — NEURAL NETWORK FORWARD PASS:

    Input x: (n_features,) → reshape to (n_features, 1)
    Weights W: (n_hidden, n_features)
    Bias b: (n_hidden,)

    z = W @ x + b    (n_hidden,)

    Or for a batch:
    X: (batch_size, n_features)
    Z = X @ W.T + b  (batch_size, n_hidden)

    This is the FUNDAMENTAL operation in neural networks.
    EVERY layer does: output = activation(input @ weights + bias)

================================================================================
7. MATRIX INVERSE
================================================================================

WHAT IS AN INVERSE?
    If A × A⁻¹ = I, then A⁻¹ is the inverse of A.

    Like division: A⁻¹ = I / A

    Only SQUARE, NON-SINGULAR matrices have inverses.

SINGULAR MATRIX:
    A matrix with determinant = 0 has no inverse.
    This happens when rows/columns are linearly dependent.

    Example: A = │ 1  2 │ → det = 1×4 - 2×2 = 0 (singular!)
                  │ 2  4 │

PSEUDO-INVERSE:
    For non-square or singular matrices:
    A⁺ = (AᵀA)⁻¹Aᵀ

    ML USE: Linear regression normal equation:
    w = (XᵀX)⁻¹Xᵀy

    This gives the OPTIMAL weights directly (no gradient descent needed).
    But it's O(n³) expensive and doesn't scale to large datasets.

8. EIGENVALUES AND EIGENVECTORS
================================================================================

WHAT ARE THEY?
    For a square matrix A, an eigenvector v satisfies:
    Av = λv

    A just STRETCHES the eigenvector (doesn't rotate it).
    λ (eigenvalue) is how much it stretches.

EXAMPLE:
    A = │ 4  2 │
        │ 1  3 │

    Eigenvalue λ₁ = 5, eigenvector v₁ = [2, 1]
    Eigenvalue λ₂ = 2, eigenvector v₂ = [-1, 1]

    Check: A × v₁ = │ 4  2 │ × │ 2 │ = │ 10 │ = 5 × │ 2 │
                     │ 1  3 │   │ 1 │   │  5 │      │ 1 │

    ✓ Av₁ = 5v₁ (eigenvalue is 5)

GEOMETRIC INTERPRETATION:
    - Eigenvectors are the DIRECTIONS that don't change under transformation
    - Eigenvalues are the MAGNITUDES of stretching in those directions
    - Large eigenvalue = the matrix stretches a lot in that direction

ML USE — PCA (Principal Component Analysis):

    Step 1: Center the data
    X_centered = X - mean(X)

    Step 2: Compute covariance matrix
    C = (1/n) X_centeredᵀ X_centered

    Step 3: Eigendecomposition
    eigenvalues, eigenvectors = eig(C)

    Step 4: Sort by eigenvalue (largest first)
    - The eigenvector with the LARGEST eigenvalue
      is the direction of MAXIMUM VARIANCE
    - This is the FIRST PRINCIPAL COMPONENT

    Step 5: Project onto top k eigenvectors
    X_pca = X_centered @ eigenvectors[:, :k]

    This REDUCES dimensionality while preserving maximum variance.

    WHY IT WORKS:
    - Eigenvectors capture the "important" directions
    - Eigenvalues tell us HOW important each direction is
    - We can discard directions with small eigenvalues (low variance)

================================================================================
9. SINGULAR VALUE DECOMPOSITION (SVD)
================================================================================

ANY matrix A (m×n) can be decomposed as:

    A = U Σ Vᵀ

    U: (m×m) left singular vectors (orthogonal)
    Σ: (m×n) diagonal matrix of singular values (sorted descending)
    Vᵀ: (n×n) right singular vectors (orthogonal)

EXAMPLE:
    A = │ 1  2  3 │    (2×3 matrix)
        │ 4  5  6 │

    U, Σ, Vᵀ = svd(A)
    A ≈ U[:, :k] @ diag(Σ[:k]) @ Vᵀ[:k, :]    (low-rank approximation)

ML USE:

1. DIMENSIONALITY REDUCTION:
   Keep only top k singular values.
   X_reduced = U[:, :k] @ diag(Σ[:k])

2. RECOMMENDATION SYSTEMS:
   User-Item matrix R ≈ U @ Σ @ Vᵀ
   U = user embeddings
   V = item embeddings
   Σ = importance of latent factors

3. LATENT SEMANTIC ANALYSIS (NLP):
   Term-Document matrix → SVD → topic representations

4. IMAGE COMPRESSION:
   Store U, Σ, Vᵀ instead of full image matrix.

10. VECTOR SPACES AND LINEAR INDEPENDENCE
================================================================================

SPAN:
    The set of all possible linear combinations of vectors.

    span([1, 0], [0, 1]) = all of ℝ²

LINEAR INDEPENDENCE:
    Vectors are linearly independent if none can be written
    as a combination of the others.

    [1, 0] and [0, 1] are linearly independent
    [1, 0] and [2, 0] are linearly dependent (second = 2 × first)

BASIS:
    A set of linearly independent vectors that span the space.

    Standard basis for ℝ²: {[1,0], [0,1]}

    ML CONNECTION:
    - PCA finds a new basis for the data
    - The basis vectors (principal components) capture the most variance
    - Feature space can be transformed to a new basis

RANK:
    The number of linearly independent rows/columns.
    rank(A) = number of non-zero singular values.

    ML USE:
    - Low-rank approximation: keep only important dimensions
    - Rank-deficient matrices indicate redundant features

11. PRACTICAL EXAMPLES
================================================================================

EXAMPLE 1: Linear Regression with Normal Equation

    X = │ 1  1 │    y = │ 3 │
        │ 1  2 │        │ 5 │
        │ 1  3 │        │ 7 │

    (First column is 1s for bias term)

    w = (XᵀX)⁻¹Xᵀy

    XᵀX = │ 3  6 │    Xᵀy = │ 15 │
           │ 6  14│           │ 34 │

    (XᵀX)⁻¹ = │ 7/3   -1  │
                │ -1    1/2 │

    w = (XᵀX)⁻¹Xᵀy = │ 7/3  -1  │ × │ 15 │ = │ 1 │
                       │ -1   1/2 │   │ 34 │   │ 2 │

    Model: y = 1 + 2x
    Check: x=1→3✓, x=2→5✓, x=3→7✓

EXAMPLE 2: Cosine Similarity

    word_king = [0.2, 0.8, 0.1, 0.9]
    word_queen = [0.3, 0.7, 0.2, 0.8]

    dot = 0.06 + 0.56 + 0.02 + 0.72 = 1.36
    |king| = √(0.04 + 0.64 + 0.01 + 0.81) = √1.5 = 1.225
    |queen| = √(0.09 + 0.49 + 0.04 + 0.64) = √1.26 = 1.122

    cosine_sim = 1.36 / (1.225 × 1.122) = 0.995

    Very similar! (Both are royalty-related words)

EXAMPLE 3: PCA (simplified)

    X = │ 2  1 │    (2 samples, 2 features)
        │ 1  3 │

    Mean: [1.5, 2]
    X_centered = │ 0.5  -1 │
                 │-0.5   1 │

    Covariance: C = (1/2) Xᵀ_centered X_centered = │ 0.5  -0.5 │
                                                     │-0.5   0.5 │

    Eigenvalues: 1.0, 0.0
    Eigenvectors: [1, -1], [1, 1]

    The first principal component [1, -1] captures ALL the variance.
    We can reduce from 2D to 1D using this direction.

================================================================================
12. COMMON MISTAKES
================================================================================

MISTAKE 1: Matrix multiplication order matters
    A @ B ≠ B @ A (in general)
    Only commutative for diagonal matrices.

MISTAKE 2: Forgetting dimension requirements
    A: (3, 4) @ B: (5, 2) → ERROR! Inner dimensions don't match.
    Must be: A: (m, k) @ B: (k, n) = C: (m, n)

MISTAKE 3: Confusing transpose with inverse
    Aᵀ ≠ A⁻¹ (in general)
    Only true for orthogonal matrices.

MISTAKE 4: Ignoring numerical stability
    Computing (XᵀX)⁻¹ directly can be numerically unstable.
    Use np.linalg.solve() or np.linalg.pinv() instead.

MISTAKE 5: Not centering data for PCA
    PCA requires CENTERED data (mean = 0).
    Always subtract the mean before computing covariance.
