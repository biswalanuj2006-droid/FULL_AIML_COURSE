================================================================================
ALGEBRA EXERCISES
================================================================================

A1: In the linear model y = 0.5x + 10, what is y when x = 20?

A2: The loss function L(w) = (w - 4)² has its minimum at what value of w?

A3: Compute σ(3) = 1/(1 + e⁻³). Show your work.

A4: If log₂(x) = 5, what is x?

A5: Given y = wx + b, if w = 2 and b = -3, find x when y = 7.

L3: What is the transpose of [[1, 2, 3], [4, 5, 6]]?

L4: Compute the L2 norm of [3, 4].

L5: For a dataset X with shape (1000, 10), what is the shape of X.T @ X?

L6: What does an eigenvalue of 0 tell you about a matrix?

CALCULUS EXERCISES

C1: Find d/dx(3x³ + 2x² - 5x + 1).

C2: Find d/dx(e²ˣ) using the chain rule.

C3: If f(x, y) = x²y + xy², find ∂f/∂x and ∂f/∂y.

C4: The sigmoid is σ(z) = 1/(1+e⁻ᶻ). Show that σ'(z) = σ(z)(1-σ(z)).

ANSWERS
================================================================================

ALGEBRA:
A1: y = 0.5(20) + 10 = 20
A2: w = 4 (minimum of (w-4)² is at w=4)
A3: σ(3) = 1/(1+e⁻³) = 1/(1+0.0498) = 0.953
A4: x = 2⁵ = 32
A5: 7 = 2x - 3 → x = 5

LINEAR ALGEBRA:
L1: 1×2 + 3×4 + 5×6 = 2 + 12 + 30 = 44
L2: [[19, 22], [43, 50]]
L3: [[1, 4], [2, 5], [3, 6]]
L4: √(9+16) = 5
L5: (10, 10)
L6: The matrix is singular (not invertible)

CALCULUS:
C1: 9x² + 4x - 5
C2: 2e²ˣ
C3: ∂f/∂x = 2xy + y², ∂f/∂y = x² + 2xy
C4: σ'(z) = e⁻ᶻ/(1+e⁻ᶻ)² = σ(z) × (1-σ(z))
C5: dL/dw = -(2/n)Σ(yᵢ-wxᵢ)xᵢ

PROBABILITY:
P1: 3/8 = 0.375
P2: P(A|B) = 0.2/0.4 = 0.5
P3: P(disease|pos) = (0.9×0.02)/(0.9×0.02+0.1×0.98) = 0.155
P4: E[X] = 3.5
P5: Poisson (count data)

STATISTICS:
S1: mean=15, var=50, std=7.07
S2: High negative correlation → remove one (multicollinearity)
S3: 0.92 ± 1.96×√(0.92×0.08/1000) = [0.903, 0.937]
S4: Q1=3, Q3=11, IQR=8
S5: When class distribution is imbalanced

OPTIMIZATION:
O1: w = w - 0.1 × 5.0 = w - 0.5
O2: Adam adapts learning rate per parameter and uses momentum
O3: Batch=all data, SGD=1 sample, mini-batch=B samples
O4: Overfitting → use early stopping, regularization, more data
O5: PCA requires centered data (mean=0) for correct variance computation
