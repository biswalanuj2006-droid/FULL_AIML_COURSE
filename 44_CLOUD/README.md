# Module 44: Cloud for AI

Running AI workloads on AWS/Azure/GCP: compute, storage, containers, and
managed ML services — with cost-awareness.

## What You Will Learn

- Cloud basics: regions, IAM, VPC, billing concepts
- Compute: VMs (EC2) vs containers (ECS/EKS) vs serverless (Lambda)
- Object storage (S3) for data and models
- Managed databases (RDS/Aurora) and caching
- Managed ML: SageMaker/Azure ML/Vertex AI concepts
- GPU instances and cost realities
- Deploying your Dockerized model to the cloud
- Monitoring: CloudWatch/Azure Monitor equivalents
- Cost control: right-sizing, spot, autoscaling, budgets
- Security: least-privilege IAM, secrets, network policies
