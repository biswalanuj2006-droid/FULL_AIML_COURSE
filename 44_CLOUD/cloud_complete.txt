2. DEPLOYING ML API TO CLOUD
================================================================================

AWS ECS (Elastic Container Service)
------------------------------------
1. Push Docker image to ECR (Elastic Container Registry)
2. Create ECS cluster
3. Define task with image
4. Create service
5. Set up load balancer

GCP CLOUD RUN (Simplest)
-------------------------
# Build and push image
gcloud builds submit --tag gcr.io/my-project/ml-api

# Deploy
gcloud run deploy ml-api \
  --image gcr.io/my-project/ml-api \
  --platform managed \
  --port 8000 \
  --min-instances 0 \
  --max-instances 10

AZURE CONTAINER INSTANCES
--------------------------
az container create \
  --resource-group myRG \
  --name ml-api \
  --image myregistry/ml-api:latest \
  --ports 8000 \
  --dns-name-label ml-api

================================================================================
3. SERVERLESS DEPLOYMENT
================================================================================

AWS LAMBDA + API GATEWAY
-------------------------
# Package ML model as Lambda function
import joblib
import numpy as np

model = joblib.load('/opt/ml/model.pkl')

def lambda_handler(event, context):
    features = np.array(event['features']).reshape(1, -1)
    prediction = model.predict(features)
    return {
        'statusCode': 200,
        'body': {'prediction': prediction.tolist()}
    }

GCP CLOUD FUNCTIONS
--------------------
def predict(request):
    import json
    data = request.get_json()
    features = data['features']
    prediction = model.predict([features])
    return json.dumps({'prediction': prediction.tolist()})
