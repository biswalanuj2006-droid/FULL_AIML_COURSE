# Python PDF Notes (extracted) - Supplementary Reading

Source: `PYTHON NOTES.zip` (third-party slide decks, 24 modules).
These are the web/backend-relevant ones, extracted to plain text with
pypdf (page markers `--- PAGE n ---` preserved) so they are greppable
and diffable inside the course.

| File | Slides | Maps to course module |
|------|--------|----------------------|
| `12_postgresql_notes.txt`    | Module 12 - PostgreSQL apps   | 40_DATABASES |
| `14_django_notes.txt`        | Module 14 - Django            | 37_DJANGO |
| `15_flask_notes.txt`         | Module 15 - Flask             | 36_FLASK |
| `16_rest_apis_django_notes.txt` | Module 16 - REST APIs with Django | 38_REST_APIS, 37_DJANGO |

Usage rule: these are optional *second explanations*. The course's own
`*_complete.txt` lessons are deeper and exercise-backed; read these
only when you want a different angle or a lighter first pass.

Note on GraphQL: the zip contains NO GraphQL material (verified by
searching every extracted page). The closest is Module 16, which is
classic REST with the Django REST Framework. If you want a GraphQL
reference, the course's 38_REST_APIS module is the natural home for a
future `graphql.txt` lesson (Graphene/Strawberry + why/when to choose
GraphQL over REST).
