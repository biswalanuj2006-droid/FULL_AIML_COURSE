## DIAGRAM 3: ATTENTION MECHANISM (Scaled Dot-Product)

```
Input: Query (Q), Key (K), Value (V)
        ↓
┌───────────────────────────────────────────────┐
│                                               │
│    Q × Kᵀ  →  Attention Scores               │
│       ↓                                       │
│    ÷ √d_k  →  Scaled Scores                  │
│       ↓                                       │
│    Softmax →  Attention Weights               │
│       ↓                                       │
│    Weights × V  →  Output                     │
│                                               │
└───────────────────────────────────────────────┘

Mathematical Formula:
    Attention(Q, K, V) = softmax(QKᵀ / √d_k) × V

Where:
    Q = Query matrix    (sequence_length × d_model)
    K = Key matrix      (sequence_length × d_model)
    V = Value matrix    (sequence_length × d_model)
    d_k = dimension of keys (scaling factor)
```

## DIAGRAM 5: LSTM CELL ARCHITECTURE

```
    ┌─────────────────────────────────────────────┐
    │              LSTM Cell                       │
    │                                              │
    │  C_{t-1} ──────→ [×] ──────→ [+] ────→ C_t │
    │                   ↑           ↑              │
    │              ┌────┴────┐  ┌───┴───┐          │
    │              │ Forget  │  │ Input │          │
    │              │ Gate    │  │ Gate  │          │
    │              │ σ(W·[h,x])│ tanh(W·[h,x])│   │
    │              └─────────┘  └───────┘          │
    │                                              │
    │  h_{t-1} ──→ [tanh] ──→ [×] ──→ [×] ──→ h_t│
    │                            ↑                  │
    │                      ┌─────┴─────┐            │
    │                      │ Output    │            │
    │                      │ Gate      │            │
    │                      │ σ(W·[h,x])│            │
    │                      └───────────┘            │
    └─────────────────────────────────────────────┘

    Gates:
    Forget: f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
    Input:  i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
    Output: o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
    Candidate: C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
    Cell: C_t = f_t * C_{t-1} + i_t * C̃_t
    Hidden: h_t = o_t * tanh(C_t)
```

## DIAGRAM 12: GAN ARCHITECTURE

```
┌─────────────────────────────────────────────────┐
│              GAN (Generative Adversarial Network) │
│                                                  │
│  Random Noise z                                  │
│       ↓                                          │
│  ┌──────────────┐                                │
│  │  GENERATOR   │                                │
│  │  (creates    │──→ Fake Image                  │
│  │   fake data) │     ↓                          │
│  └──────────────┘     ↓                          │
│                    ┌──────────────┐               │
│                    │ DISCRIMINATOR│               │
│  Real Image ──────→│ (classifies  │──→ Real/Fake │
│                    │  real/fake)  │               │
│                    └──────────────┘               │
│                                                  │
│  Training:                                       │
│  1. Train Discriminator: distinguish real/fake   │
│  2. Train Generator: fool Discriminator          │
│  3. Repeat until Generator creates realistic     │
│     images                                       │
│                                                  │
│  Loss:                                           │
│  min_G max_D V(D,G) = E[log D(x)] + E[log(1-D(G(z)))] │
└─────────────────────────────────────────────────┘
```
