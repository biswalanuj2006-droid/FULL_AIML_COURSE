   /         \ /         \ /
  /           \           \

3. RNN / LSTM UNROLLING
================================================================================

TIME STEP:    t=0           t=1           t=2           t=3

              ┌───┐         ┌───┐         ┌───┐         ┌───┐
  x₀ ───────→│ h │────────→│ h │────────→│ h │────────→│ h │────→ output
              └───┘         └───┘         └───┘         └───┘

RNN: Same weights at every time step (parameter sharing)

LSTM: Has 3 gates + cell state

              ┌──────────────────────────┐
              │   CELL STATE (C_t)        │ ← Highway for long-range memory
              │   ════════════════════     │
              │   ↑ forget  ↑ input  ↑ output│
              └──────────────────────────┘

GATES:
  Forget gate:  f = σ(W_f · [h_{t-1}, x_t])     → what to forget
  Input gate:   i = σ(W_i · [h_{t-1}, x_t])     → what to store
  Output gate:  o = σ(W_o · [h_{t-1}, x_t])     → what to output

7. GRADIENT DESCENT OPTIMIZATION
================================================================================

LOSS SURFACE (2D cross-section):

Loss
  │     ╭─╮
  │    ╭╯ ╰╮        ← Local minimum
  │   ╭╯   ╰╮
  │  ╭╯     ╰─╮
  │ ╭╯        ╰──╮
  │╭╯             ╰─── Global minimum
  │╰╮                    ↓
  │  ╰╮                ╭──╮
  │    ╰╮             ╭╯  ╰╮
  │      ╰───────────╯    ╰──
  └──────────────────────────── Parameters

GRADIENT DESCENT UPDATE:
  w_new = w_old - learning_rate × gradient

  If gradient > 0 → move left (decrease w)
  If gradient < 0 → move right (increase w)

ADAM OPTIMIZER:
  Combines momentum (velocity) + RMSProp (adaptive learning rate)
  m = β₁·m + (1-β₁)·gradient      (momentum)
  v = β₂·v + (1-β₂)·gradient²     (second moment)
  w = w - lr · m̂ / (√v̂ + ε)

10. BIAS-VARIANCE TRADEOFF
================================================================================

ERROR
  │
  │╲                    ╱
  │ ╲                  ╱
  │  ╲   TOTAL ERROR  ╱
  │   ╲      ╭──╮    ╱
  │    ╲    ╱    ╲  ╱
  │     ╲  ╱      ╲╱  ← Sweet spot
  │      ╲╱
  │     ╱╲

  │   ╱    ╲
  │  ╱ VARIANCE
  │ ╱
  │╱ BIAS
  └──────────────────── MODEL COMPLEXITY →

  Low complexity → High bias (underfitting)
  High complexity → High variance (overfitting)
  Goal → Find the minimum total error

11. RAG vs FINE-TUNING vs PROMPTING
================================================================================

┌─────────────────────────────────────────────────────────┐
│                    DECISION GUIDE                        │
├──────────────┬──────────────┬───────────────────────────┤
│  PROMPTING   │ FINE-TUNING  │         RAG               │
├──────────────┼──────────────┼───────────────────────────┤
│ Quick setup  │ Needs data   │ Needs knowledge base      │
│ No training  │ Training req │ Retrieval + generation    │
│ General task │ Domain adapt │ Grounded answers          │
│ Context limit│ Long context  │ Sources verifiable        │
│ No custom    │ Custom style  │ Always fresh data         │
│ Cheap        │ Expensive    │ Moderate cost             │
│ Hallucination│ Hallucination│ Reduced hallucination     │
└──────────────┴──────────────┴───────────────────────────┘

WHEN TO USE:
- Prompting: Simple tasks, few examples needed
- Fine-tuning: Consistent format, domain terminology, custom behavior
- RAG: Private data, verifiable sources, frequently updated knowledge
