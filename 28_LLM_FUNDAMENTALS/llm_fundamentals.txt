================================================================================
1. WHAT ARE LLMs?
================================================================================

INTUITION
---------
Large Language Models are transformer-based neural networks trained
on massive text datasets to understand and generate human language.

Key characteristics:
- Billions of parameters
- Trained on trillions of tokens
- Emergent abilities at scale (reasoning, coding, math)
- Can be prompted for various tasks without task-specific training

2.1 OPENAI API
---------------
from openai import OpenAI

client = OpenAI(api_key="your-api-key")

# Basic completion
response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain machine learning in one paragraph."}
    ],
    temperature=0.7,
    max_tokens=500
)

print(response.choices[0].message.content)

2.2 HUGGING FACE PIPELINE
---------------------------
from transformers import pipeline

# Text generation
generator = pipeline('text-generation', model='gpt2')
output = generator("The future of AI is", max_length=100)

# Text classification
classifier = pipeline('text-classification', model='distilbert-base-uncased-finetuned-sst-2-english')

2.3 HUGGING FACE LIBRARY
--------------------------
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

tokenizer = AutoTokenizer.from_pretrained('gpt2')
model = AutoModelForCausalLM.from_pretrained('gpt2')

input_text = "The future of AI"
inputs = tokenizer(input_text, return_tensors='pt')

with torch.no_grad():
    outputs = model.generate(
        **inputs,
        max_length=100,
        temperature=0.7,
        do_sample=True,
        top_p=0.9
    )

print(tokenizer.decode(outputs[0], skip_special_tokens=True))

================================================================================
3. STREAMING
================================================================================

INTUITION
---------
Instead of waiting for the complete response, receive tokens as they're
generated. Better user experience for long responses.

OPENAI STREAMING
-----------------
stream = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Write a story"}],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)

HUGGING FACE STREAMING
-----------------------
from transformers import TextIteratorStreamer
from threading import Thread

streamer = TextIteratorStreamer(tokenizer, skip_prompt=True)

thread = Thread(target=model.generate, kwargs={
    **inputs, "max_length": 200, "streamer": streamer
})
thread.start()

for text in streamer:
    print(text, end="", flush=True)

7. MODEL SELECTION GUIDE
================================================================================

| MODEL        | CAPABILITY        | COST    | SPEED  | BEST FOR           |
|--------------|-------------------|---------|--------|--------------------|
| GPT-4        | Excellent         | High    | Medium | Complex reasoning  |
| GPT-4o       | Excellent         | Medium  | Fast   | General purpose    |
| GPT-3.5      | Good              | Low     | Fast   | Simple tasks       |
| Claude 3     | Excellent         | Medium  | Medium | Long context       |
| LLaMA 3      | Very Good         | Free*   | Varies | Open-source        |
| Gemini Pro   | Very Good         | Medium  | Fast   | Multimodal         |

*Self-hosted or via API

CHOOSING:
- Need best quality → GPT-4 or Claude 3
- Need speed + cost → GPT-3.5 or GPT-4o-mini
- Need privacy → self-host LLaMA
- Need long context → Claude 3 (200K tokens)
- Need multimodal → GPT-4o or Gemini

================================================================================
8. COMMON MISTAKES
================================================================================

MISTAKE 1: Not using system prompt
  WRONG: Only using user messages
  RIGHT: Set clear role and behavior with system prompt

MISTAKE 2: Sending entire documents
  RIGHT: Use RAG or chunk long documents

MISTAKE 3: Not handling rate limits
  RIGHT: Implement retries with exponential backoff

MISTAKE 4: Hardcoding API keys
  RIGHT: Use environment variables

MISTAKE 5: Not evaluating outputs
  RIGHT: Log, test, and monitor LLM outputs in production
