## PROJECT 2 — DOCUMENT Q&A SYSTEM (Level 2)

### Problem Statement
Build a Q&A system that answers questions from documents.

### Requirements
- Load documents (PDF, TXT, MD)
- Split into chunks
- Create embeddings
- Store in vector database
- Retrieve relevant chunks
- Generate answers with LLM
- Add citations

### Architecture
```
Documents → Chunking → Embedding → Vector DB
                                      ↑
User Query → Embedding → Search
                                      ↓
                          Retrieved chunks + Query → LLM → Answer
```

### Expected Output
- Working Q&A system
- Citation support
- Multiple document types
- API endpoint
