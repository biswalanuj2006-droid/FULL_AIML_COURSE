# Module 23: NLP

Turning text into features and models — from preprocessing to classical NLP,
then into the deep sequence models that follow.

## What You Will Learn

- Text preprocessing: tokenization, normalization, stopwords
- Stemming vs lemmatization; POS tagging; NER
- Bag of Words, n-grams, TF-IDF: math and intuition
- Text classification & sentiment analysis with sklearn
- Classical pipelines with NLTK/spaCy
- Text similarity (cosine), topic modeling overview
- Evaluation for NLP: accuracy, F1, confusion on labels
- When classical NLP is right vs when you need embeddings/transformers
