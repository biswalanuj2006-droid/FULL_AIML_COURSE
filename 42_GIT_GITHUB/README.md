# Module 42: Git & GitHub

Version control for code, notebooks, and model repos — plus collaboration
workflows and CI/CD foundations.

## What You Will Learn

- Git basics: init, clone, add, commit, status, log
- Branching, merging, rebasing; when to use each
- Remotes, push/pull, and resolving conflicts
- Pull requests and code review workflows
- .gitignore discipline and protecting secrets
- Stash, cherry-pick, revert, and reset (dangerous commands)
- Tags and releases
- GitHub Actions basics: CI for tests and linting
- Git for notebooks and large files (Git LFS concept)
- Versioning ML code + data together (link to 33_MLOPS)
