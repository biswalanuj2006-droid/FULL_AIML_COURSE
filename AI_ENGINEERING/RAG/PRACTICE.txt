VERIFIED ANSWERS (selected numerics)
================================================================================
  R0-M1  8k - 1k - 200 = 6800 tokens for evidence; 6800/500 = 13 chunks
         (13 x 500 = 6500 <= 6800).
  R0-M2  Yes for normalized vectors: cos(u,v) = u.v/(|u||v|) = u.v when
         both are unit norm.
  R0-M3  IDF = ln(100/10) = ln(10) ~= 2.303.
  R1-M1  IDF = ln(1000/10) = ln(100) ~= 4.605.
  R1-M2  cos = 1*0.707/1 = 0.707 -> 45 degrees.
  R1-M3  chunks = ceil((2000-50)/(400-50)) = ceil(1950/350) = 6;
         total tokens ~ 2000 + 5*50 = 2250 (overlap duplicates 250).
  R2-M1  RRF = 1/(60+2) + 1/(60+5) = 0.01613 + 0.01538 = 0.03151.
  R2-M2  Rerank 50 with 20ms each in batches of 8 -> ceil(50/8)=7
         batches -> ~140ms + dense 5ms + overhead ~ 150-160ms total.
  R2-M3  Union {d1,d2,d3,d4,d5}: 5 before dedupe-listed, 5 unique.
  R3-M1  Independent: 0.9 x 0.9 = 0.81. Dependent (second searches
         using first's output): <= 0.9; error compounds through the
         chain - this is why multi-hop needs verification.
  R3-M2  32k - 1k - 300 - 2k = 28,700 tokens for evidence; 28700/600
         ~= 47 chunks of 600.
  R3-M3  In: 3 x 1000 + 3000 = 6000 tokens -> $0.03. Out: 3 x 200 +
         500 = 1100 -> $0.0165. Total ~ $0.047 per query.
  R4-M1  Relevant {A,B}: hit@3 yes (A at 1) = 1. recall@5 = 2/2 = 1.
         precision@3 = A relevant of top3 {A,X,B} -> 2/3 = 0.667.
         MRR = 1/1 = 1.0.
  R4-M2  rel: B=3, A=2, X=0 (assume X irrelevant). DCG = 3 + 2/ln2
         + 0 ~= 3 + 2.885 = 5.885. IDCG = 3 + 2/log2(2) + 1/log2(3)
         = 3 + 2 + 0.631 = 5.631 -> wait, IDCG uses the top graded
         rels sorted desc [3,2,1] -> 3 + 2/log2(2) + 1/log2(3) =
         3 + 2 + 0.631 = 5.631. But if only two docs are relevant
         (A,B), ideal ranking [B,A] -> IDCG = 3 + 2/log2(2) = 5.0;
         NDCG = 5.885/5.0 would exceed 1, which signals the X graded
         0 assumption is wrong: with graded [3,2,1] there are three
         graded docs. Use rel B=3,A=2,X=1: DCG = 3 + 2/log2(2) +
         1/log2(3) = 5.631; IDCG (order B,A,X) = same 5.631 -> NDCG
         1.0 only if ranked perfectly; a ranking [A,B,X] gives DCG =
         2 + 3/log2(2) + 1/log2(3) = 2+3+0.631=5.631 coincidentally;
         the point: NDCG compares against the ideal order. Recompute
         cleanly: ideal order by rel desc = [3,2,1] -> IDCG = 3 +
         2/log2(2) + 1/log2(3) = 5.631. Ranking [B,A,X] = ideal ->
         NDCG = 1.0.
  R4-M3  80% agreement means a 2% delta is below the noise floor of
         the judge; report CIs and widen the sample before trusting
         small deltas.
  R4-M4  p=0.9, n=10: approx 95% CI ~ p +- 1.96*sqrt(p(1-p)/n) =
         0.9 +- 1.96*0.0949 = [0.71, 1.0] (clipped) - a 10-sample
         rate is very noisy.
