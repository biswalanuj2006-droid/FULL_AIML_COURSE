1. WHAT IS CLUSTERING?
================================================================================

Clustering = Grouping similar data points together WITHOUT labels.

    Supervised: X → y (we have labels)
    Unsupervised: X → clusters (no labels)

    ┌─────────────────────────────────────┐
    │  ○ ○ ○    ● ● ●                    │
    │  ○ ○ ○    ● ● ●    ▲ ▲ ▲           │
    │  ○ ○ ○    ● ● ●    ▲ ▲ ▲           │
    │   Group 1  Group 2  Group 3         │
    └─────────────────────────────────────┘

USE CASES:
    - Customer segmentation (group similar customers)
    - Anomaly detection (points far from any cluster)
    - Document clustering (group similar articles)
    - Image segmentation (group similar pixels)
    - Feature engineering (cluster ID as feature)
    - Data exploration (understand data structure)

2. K-MEANS CLUSTERING
================================================================================

INTUITION:
    Find K cluster centers and assign each point to the nearest center.

ALGORITHM:
    1. Initialize K random centroids
    2. Assign each point to nearest centroid
    3. Recalculate centroids as mean of assigned points
    4. Repeat 2-3 until convergence

MATHEMATICS:
    Objective: Minimize within-cluster sum of squares (WCSS)

    J = Σₖ Σₓ∈Cₖ ||x - μₖ||²

    where:
    K = number of clusters
    Cₖ = set of points in cluster k
    μₖ = centroid of cluster k
    ||x - μₖ||² = squared Euclidean distance

IMPLEMENTATION:
    from sklearn.cluster import KMeans

    kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
    labels = kmeans.fit_predict(X)
    centroids = kmeans.cluster_centers_

    # Inertia (WCSS)
    print(f"Inertia: {kmeans.inertia_:.2f}")

CHOOSING K — ELBOW METHOD:
    inertias = []
    K_range = range(1, 11)
    for k in K_range:
        km = KMeans(n_clusters=k, random_state=42)
        km.fit(X)
        inertias.append(km.inertia_)

    plt.plot(K_range, inertias, 'bo-')
    plt.xlabel('K')
    plt.ylabel('Inertia')
    plt.title('Elbow Method')
    # Look for the "elbow" where inertia stops decreasing rapidly

CHOOSING K — SILHOUETTE SCORE:
    from sklearn.metrics import silhouette_score

    scores = []
    for k in range(2, 11):
        km = KMeans(n_clusters=k, random_state=42)
        labels = km.fit_predict(X)
        scores.append(silhouette_score(X, labels))

    best_k = range(2, 11)[np.argmax(scores)]

PROS:
    - Simple and fast
    - Scales well to large datasets
    - Guaranteed convergence

CONS:
    - Must specify K
    - Assumes spherical clusters
    - Sensitive to initialization
    - Sensitive to outliers
    - Struggles with non-convex shapes

3. DBSCAN — DENSITY-BASED CLUSTERING
================================================================================

INTUITION:
    Groups points that are closely packed together.
    Points in low-density regions are marked as outliers.

PARAMETERS:
    eps (ε): Maximum distance between two points to be neighbors
    min_samples: Minimum points to form a dense region

ALGORITHM:
    1. Pick an unvisited point
    2. Find all points within ε distance (neighbors)
    3. If neighbors >= min_samples → Core point → Start cluster
    4. Expand cluster by adding reachable neighbors
    5. If neighbors < min_samples → Noise point (outlier)
    6. Repeat until all points visited

IMPLEMENTATION:
    from sklearn.cluster import DBSCAN

    dbscan = DBSCAN(eps=0.5, min_samples=5)
    labels = dbscan.fit_predict(X)

    # Labels: -1 means noise/outlier
    n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
    n_noise = list(labels).count(-1)

CHOOSING eps AND min_samples:
    # eps: Use k-distance graph
    from sklearn.neighbors import NearestNeighbors

    nn = NearestNeighbors(n_neighbors=5)
    nn.fit(X)
    distances, _ = nn.kneighbors(X)
    k_distances = np.sort(distances[:, -1])

    plt.plot(k_distances)
    plt.xlabel('Points')
    plt.ylabel('5th Nearest Neighbor Distance')
    # Look for the "elbow" → that's a good eps

    # min_samples: Rule of thumb = 2 × n_features
    # Or: min_samples >= dimensionality + 1

PROS:
    - Finds arbitrary-shaped clusters
    - Automatically detects outliers
    - No need to specify K
    - Works well with spatial data

CONS:
    - Struggles with varying densities
    - Sensitive to eps and min_samples
    - Not good for high-dimensional data
    - Can be slow on large datasets

4. HIERARCHICAL CLUSTERING
================================================================================

INTUITION:
    Build a tree of clusters (dendrogram).
    Either merge (agglomerative) or split (divisive).

AGGLOMERATIVE (bottom-up):
    1. Start with each point as its own cluster
    2. Merge the two closest clusters
    3. Repeat until one cluster remains

LINKAGE CRITERIA:
    - Single: Minimum distance between clusters
    - Complete: Maximum distance between clusters
    - Average: Average distance between clusters
    - Ward: Minimize variance within clusters (RECOMMENDED)

IMPLEMENTATION:
    from sklearn.cluster import AgglomerativeClustering
    from scipy.cluster.hierarchy import dendrogram, linkage

    # Dendrogram
    Z = linkage(X, method='ward')
    dendrogram(Z)
    plt.title('Dendrogram')
    plt.show()

    # Cut at desired number of clusters
    clustering = AgglomerativeClustering(n_clusters=3)
    labels = clustering.fit_predict(X)

PROS:
    - Produces dendrogram (visual hierarchy)
    - No need to specify K upfront (can cut dendrogram)
    - Deterministic (no random initialization)
    - Works well with compact clusters

CONS:
    - O(n²) memory (stores distance matrix)
    - Slow on large datasets (>10K points)
    - Sensitive to noise

================================================================================
5. GAUSSIAN MIXTURE MODELS (GMM)
================================================================================

INTUITION:
    Assumes data is generated from K Gaussian distributions.
    Each cluster is an ellipse (not just a sphere like K-Means).

PROBABILISTIC:
    Instead of hard assignments, gives PROBABILITY of belonging to each cluster.

IMPLEMENTATION:
    from sklearn.mixture import GaussianMixture

    gmm = GaussianMixture(n_components=3, random_state=42)
    gmm.fit(X)
    labels = gmm.predict(X)
    probabilities = gmm.predict_proba(X)  # Soft assignments

CHOOSING K — BIC/AIC:
    bics = []
    for k in range(1, 11):
        gmm = GaussianMixture(n_components=k, random_state=42)
        gmm.fit(X)
        bics.append(gmm.bic(X))

    best_k = range(1, 11)[np.argmin(bics)]

PROS:
    - Soft assignments (probabilities)
    - Can model elliptical clusters
    - Probabilistic framework
    - Works well with overlapping clusters

CONS:
    - Must specify K
    - Assumes Gaussian distributions
    - Can converge to local optima
    - Computationally expensive

6. CLUSTERING EVALUATION
================================================================================

SILHOUETTE SCORE:
    from sklearn.metrics import silhouette_score

    score = silhouette_score(X, labels)
    Range: -1 to 1
    1 = well-matched to own cluster
    0 = on cluster boundary
    -1 = possibly wrong cluster

DAVIES-BOULDIN INDEX:
    from sklearn.metrics import davies_bouldin_score

    score = davies_bouldin_score(X, labels)
    Lower is better (0 = best)

CALINSKI-HARABASZ INDEX:
    from sklearn.metrics import calinski_harabasz_score

    score = calinski_harabasz_score(X, labels)
    Higher is better

7. ALGORITHM COMPARISON
================================================================================

┌──────────────────┬──────────┬──────────┬──────────┬──────────┐
│ Algorithm        │ K needed │ Shapes   │ Outliers │ Speed    │
├──────────────────┼──────────┼──────────┼──────────┼──────────┤
│ K-Means          │ Yes      │ Spherical│ No       │ Fast     │
│ DBSCAN           │ No       │ Arbitrary│ Yes      │ Moderate │
│ Hierarchical     │ Optional │ Arbitrary│ No       │ Slow     │
│ GMM              │ Yes      │ Elliptical│ No      │ Moderate │
└──────────────────┴──────────┴──────────┴──────────┴──────────┘

WHEN TO USE:
    - K-Means: Large data, spherical clusters, known K
    - DBSCAN: Unknown K, need outlier detection, spatial data
    - Hierarchical: Small data, need hierarchy visualization
    - GMM: Overlapping clusters, need probabilities
