### Q1. What is the time complexity of the following code?
```python
def mystery(n):
    result = 0
    for i in range(n):
        for j in range(i, n):
            result += 1
    return result
```
A) O(n)  B) O(n²)  C) O(n³)  D) O(n log n)

<details><summary>Answer</summary>B) O(n²) — Sum of (n-i) for i=0 to n-1 = n(n-1)/2 = O(n²)</details>

```python
class Stack:
    def __init__(self):
        self.items = []
```

### Q13. Implement BFS on a graph. What data structure does it use?
```python
from collections import deque
def bfs(graph, start):
    visited = set([start])
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```

## SECTION 3: ALGORITHMS (10 Questions)

### Q21. Implement binary search. What is its time complexity?
```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target: return mid
        elif arr[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
```
<details><summary>Answer</summary>O(log n) — halves search space each iteration</details>

### Q29. Implement Kadane's algorithm.
```python
def max_subarray(nums):
    max_sum = current = nums[0]
    for num in nums[1:]:
        current = max(num, current + num)
        max_sum = max(max_sum, current)
    return max_sum
```
What is its time and space complexity?
<details><summary>Answer</summary>O(n) time, O(1) space</details>

### Q30. What is the time complexity of the following?
