RUN & OBSERVE

2. Save 8 test images with their predicted vs true labels; find the
   failure patterns (which digits get confused?).

MODIFY
3. Change kernel size 3x3 -> 5x5 (first conv): accuracy, params, and
   receptive field per layer - verify the field math manually.
4. Add a second conv block; compare accuracy per epoch. Then remove the
   final pooling and note what breaks (dimension mismatch / accuracy).
5. Add data augmentation (random shifts/rotations with torchvision
   transforms) and measure the train-test gap change.
6. Switch to SGD(lr=0.01, momentum=0.9) from Adam: compare convergence
   speed in the first 3 epochs (the optimizer card in action).

DEBUG

   show the accuracy drop and explain why eval mode matters.
8. Resize or channel mismatch: feed 28x28x1 as if it were 3-channel and
   fix the input reshape - read the error message carefully.
9. Set batch size 1 (or a number that doesn't divide the dataset):
   watch for the "dropped last batch" and handle with drop_last.

BUILD (mini)

    3x3 kernel and verify it matches torch's conv2d on random input.
11. Transfer learning: load a torchvision pretrained ResNet-18, freeze
    features, retrain the head on a small dataset; compare with the
    from-scratch CNN accuracy at the same epoch budget (the 32_FINE_
    TUNING lesson in code).
