CONCEPTUAL

    negative gradient, add scaled prediction).
 2. Why does boosting fit RESIDUALS (or negative gradients) instead of
    the target directly?

 4. What is the learning rate (shrinkage) and why does lowering it
    require more trees?
 5. What role do shallow trees (max_depth=1..3) play in boosting?
 6. Why can boosting overfit if you add too many trees? What are the
    three main controls (n_estimators, lr, subsample/regularization)?
 7. For regression with squared error, what exactly is each tree fit
    to?
 8. How does subsampling (stochastic GB) help and what does it cost?

NUMERICAL (hand-compute a tiny 2-tree GB regressor)
 9. Targets y=[2, 4, 6], constant init F0 = mean(y). Compute residuals.
10. Fit a stump (depth-1 tree) to those residuals; state its prediction
    for each sample (split midpoints allowed).
11. Update F1 = F0 + lr * tree(x) with lr=0.5. Compute the new
    predictions and the new residuals.
12. Compute MSE after 0, 1, and 2 boosting rounds to see the decline.

CODE (write and run)
13. Implement a GradientBoostingRegressor using your decision tree as
    the weak learner: n_estimators, learning_rate, max_depth params.
14. Plot train/test MSE vs n_estimators for lr in {0.01, 0.1, 1.0} -
    identify overfitting onset for each lr.
15. Add subsample (stochastic GB): fit each tree on a random 80% and
    compare the test curve.
16. Extend to classification: fit trees to the negative gradient of log
    loss (residual = y - p); predict via sigmoid(sum of trees).
17. Compare vs sklearn GradientBoostingRegressor/HistGradientBoosting on
    the same data: accuracy/MSE + training time.
