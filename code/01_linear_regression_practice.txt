## EASY (10 Questions)

1. What is the equation for simple linear regression?
   Answer: y = wx + b where w is weight, b is bias

2. What loss function does linear regression use?
   Answer: Mean Squared Error (MSE) = (1/n) Σ(y_pred - y_true)²

3. What is the gradient of MSE with respect to w?
   Answer: dw = (2/n) Xᵀ(Xw + b - y)

4. What is the gradient of MSE with respect to b?
   Answer: db = (2/n) Σ(Xw + b - y)

5. What is the closed-form solution (Normal Equation)?
   Answer: w = (XᵀX)⁻¹Xᵀy

6. What is the difference between batch, stochastic, and mini-batch gradient descent?
   Answer: Batch: all data per update. Stochastic: one sample. Mini-batch: subset of data.

7. What is R² score?
   Answer: 1 - (SS_res / SS_tot), where SS_res is sum of squared residuals, SS_tot is total sum of squares

8. What does R² = 0.85 mean?
   Answer: 85% of the variance in the target variable is explained by the model

9. What is the time complexity of the Normal Equation?
   Answer: O(n³) for matrix inversion, O(n²d) overall

10. What assumptions does linear regression make?
    Answer: Linearity, independence, homoscedasticity, normality of residuals

## MEDIUM (10 Questions)

11. Implement MSE loss from scratch.
    ```python
    def mse(y_true, y_pred):
        return np.mean((y_true - y_pred) ** 2)
    ```

12. Implement R² score from scratch.
    ```python
    def r2_score(y_true, y_pred):
        ss_res = np.sum((y_true - y_pred) ** 2)
        ss_tot = np.sum((y_true - np.mean(y_true)) ** 2)
        return 1 - (ss_res / ss_tot)
    ```

13. Modify LinearRegression to support L2 regularization (Ridge).
    ```python
    def fit_ridge(self, X, y):
        # Gradient: dw = (2/n)(Xᵀ(Xw+b-y)) + λw
        y_pred = X.dot(self.weights) + self.bias
        dw = (2/n) * X.T.dot(y_pred - y) + self.lambda_ * self.weights
    ```

14. Implement polynomial features from scratch.
    ```python
    def poly_features(X, degree):
        features = [X]
        for d in range(2, degree + 1):
            features.append(X ** d)
        return np.hstack(features)
    ```

15. Why does gradient descent sometimes fail to converge?
    Answer: Learning rate too high (oscillation), too low (slow), or features not scaled

16. What is feature scaling and why is it important for gradient descent?
    Answer: Normalizing features to similar scales so gradient descent converges faster

17. Implement standardization from scratch.
    ```python
    def standardize(X):
        mean = X.mean(axis=0)
        std = X.std(axis=0)
        return (X - mean) / std, mean, std
    ```

18. What is multicollinearity and how does it affect linear regression?
    Answer: High correlation between features — makes coefficients unstable and hard to interpret

19. What is the difference between R² and Adjusted R²?
    Answer: Adjusted R² penalizes for adding irrelevant features: 1 - (1-R²)(n-1)/(n-p-1)

20. When does linear regression fail?
    Answer: Non-linear relationships, outliers, multicollinearity, non-independent errors

21. Implement Ridge regression using the Normal Equation.
    ```python
    def ridge_normal(X, y, alpha):
        I = np.eye(X.shape[1])
        return np.linalg.inv(X.T.dot(X) + alpha * I).dot(X.T).dot(y)
    ```
