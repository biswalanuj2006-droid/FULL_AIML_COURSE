- How NumPy powers all of ML

## Why You Need It

NumPy is the foundation of the entire Python ML ecosystem. Pandas, scikit-learn, PyTorch, and TensorFlow all build on NumPy arrays. Understanding NumPy deeply means understanding how data flows through ML systems.

NumPy arrays are 10-100x faster than Python lists for numerical operations because they use contiguous memory and optimized C code under the hood.
